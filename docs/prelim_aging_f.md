# 雌の加齢で骨髄間質と骨はどう動くか（4A の雌化の検討、2026-10-13）

前提: `docs/datasets3_sc.md`（GSE210584 / GSE132040 / GSE299773 の評価）、`docs/prelim_niche.md`、`docs/prelim_chemo2.md`（gene set と GSEA の流儀）。予備段階の叩き台。
再生成（repo root から）: `uv run python -I prelim/aging_f/sc_load.py` → `sc_cluster.py GSE210584` → `sc_pseudobulk.py` → `tms_prepare.py` → `tms_de.py` → `compare.py`。
出力は `out/prelim/aging_f/`。

## 結論（先に）

1. **雌の中年（12–14 か月）の CAR 細胞には、化療（Dox）と同じ向きの変化は出ない。** 骨形成・ECM・血管が下がるという化療と加齢の共通軸（`docs/prelim_niche.md` の結論 1）は、雌の中年 CAR では見えない。
   - GSE210584 の CAR 擬似バルク（中年 9 vs 若齢 5）。ossification +1.43、osteoblast differentiation +1.42、NABA core matrisome +1.71、Hallmark angiogenesis +1.41 と、どれもむしろ ↑ 側（FDR < 0.25 で、< 0.05 ではない）。collagen fibril −1.46 と EMT −1.52 は ↓（FDR < 0.25）。
   - Dox×4 MSPC との NES の Spearman は −0.23。両方で FDR < 0.05 の 6 set のうち、同じ向きは 1 つで逆向きが 5 つ。遺伝子単位の統計量の相関は 0.08。DEG の重なりは 16 個で、そのうち同じ向きは 4 個。**Spp1 は中年 CAR で ↑（+1.12）、Dox で ↓（−1.58）と逆向き**。
2. **雌の中年 CAR で動くもの**: Igf1 ↓（−1.00, padj < 0.001。論文 Young et al. *Blood* 2024 の主張を再現）、炎症・SASP は弱く ↑（inflammatory response +1.45、TNF-α/NF-κB +1.52、IL6/JAK/STAT3 +1.37、SenMayo +1.47。いずれも FDR < 0.25 で、< 0.05 ではない）、bone resorption ↑（+1.66, FDR < 0.05）、増殖は少し ↓（G2M −1.29）。
   **HSC 保持因子（Cxcl12 +0.07、Kitl −0.30、Lepr −0.18）と ER 系（Esr1 −0.01、Greb1 +0.58 で有意でない、Pgr は検出されず）は動かない。** Il6・Il1b・Cdkn2a は CAR の擬似バルクで発現フィルタを通らなかった。
   骨芽系（osteoblast + osteo-CAR、各個体 60–140 細胞）では SenMayo +1.69、p53 +2.08、complement +1.77、apoptosis +2.01 が FDR < 0.05 で ↑、Igf1 も ↓（−1.51）。**雌の中年の間質で一番はっきりしているのは「Igf1 ↓ と、老化・p53 系の弱い ↑」**。
3. **TMS bulk の雌の骨（GSE132040）は、遺伝子単位ではほぼ何も出ない。** 12–21 か月 vs 1–6 か月（8 vs 6）の DEG は 7 個（Col10a1 ↓、Cfd・Cidec ↑、免疫グロブリン 4 個 ↑）。組成補正版は 4 個、1 か月を除くと 1 個。
   gene set では ECM・骨形成・血管・増殖・IFN・SASP・ER late がそろって ↓（FDR < 0.05）になるが、**これは主に 1–3 か月の成長期の骨（成長板の Col10a1、骨芽の Col1a1 / Bglap、E2F）との差**。1 か月を除くと、ECM・骨形成の ↓ は有意でなくなる（collagen fibril −1.52 だけが残る）。月齢を連続変数にしても、DEG 27 個のうち 24 個は Col1a1・Bglap・Col10a1 などの骨形成遺伝子の ↓。
   **雌の骨では、炎症は加齢で上がらない**（inflammatory response +1.04（有意でない）、組成補正版 −1.17、傾向 −1.48。IFN-α/γ と SASP は ↓）。
4. **雄との違い**: TMS の雄（16 vs 11）は DEG 203 個。炎症 ↑（inflammatory response +1.55、IFN-γ +1.54、myeloid activation +1.59）は既存の 4A（雄皮質骨 2.5 年）と同じ向きで、NES の Spearman は 0.55。
   ただし**組成補正（筋・血液・造血）をすると、雄の炎症 ↑ も消える**（inflammatory response −1.6 など）。Bone 試料には骨髄と付着筋が入っていて、筋の量は月齢とともに増える（Spearman: 雌 0.49、雄 0.54）。
   したがって「雄は炎症 ↑、雌は ↑ しない」という性差は、組成をそろえると言い切れない。言えるのは、**ECM・骨形成・増殖の ↓ は雌雄共通**で、雄は 12–21 か月で既に 4A と似た形になっている（DEG 120 個が重なり、そのうち 117 個が同じ向き）ということ。
5. **4A に使えるか**:
   - **TMS 雌は volcano にならない**（DEG 7 個、`volcano_4A.png` B）。時系列パネルにしても、動くのは成長期の骨形成遺伝子だけ。
   - **GSE210584 の CAR は volcano として成立する**（DEG 190 ↑ / 96 ↓、`volcano_4A.png` A）。中年群の内部のバッチに対しても頑健（下記 §2）。
     ただし中身は「Igf1 ↓、Spp1 ↑、炎症・SASP の弱い ↑」で、4A の現在のストーリー（加齢で炎症と老化が上がり、骨形成が下がる）とは骨形成の向きが合わない。化療とも同じ向きにならない。
   - 提案: **4A を雌で置き換えるのは勧めない。** 補強として、「雌の中年 CAR（個体反復つき scRNA）でも Igf1 ↓ と炎症・SASP の傾向はあり、HSC 保持因子と ER 系は動かない」を Supplementary に置くのが妥当。
     本文の「閉経・加齢」の軸を雌で語るなら、既存の OVX（A_OVX_*）と既存の加齢 LepR+（GSE130885、雌）の方が筋が通る。

## 根拠の弱い点

- **GSE210584 の CAR の module シグナルは弱い。** FDR < 0.05 の set は 12 個だけで、炎症・SASP の ↑ はどれも FDR < 0.25 止まり。DEG 数は十分だが、上位は個別の遺伝子（Cbln2、Lgr5、Snhg11 など）で、まとまったプログラムとしては出ていない。
- 中年群の内部に技術的なバッチがあり（§2）、若齢がどちらのバッチに属するかは分からない。片側だけで比べても向きは保たれるので、主結果への影響は小さいとみている。
- 擬似バルクは「分取した niche 画分のうち、クラスタで CAR と付けた細胞」で、GSE296758（Lepr-Cre;tdTomato+ のバルク）とは細胞の定義もプラットフォームも違う。化療との比較は別実験の向きを並べたもの。
- TMS の Bone は骨髄・筋・成長板の混合物。組成補正は 3 つのマーカースコアを共変量に入れただけで、デコンボリューションではない。雌は各時点 n = 2 で、検出力が低い。
- TMS の「12–21 vs 1–6 か月」は、1–3 か月の成長期の骨との差に引っ張られる。1 か月を除くと、ECM・骨形成の ↓ はほぼ消える。
- GSE299773 は雌雄混合の疑いがあるため使っていない。雌の「24 か月」に当たる単一細胞データは今回の材料に無い（GSE275179 は未処理）。
- gene set の FDR は 72 set で計算している。DEG は \|log2FC\| ≥ 1 & padj < 0.05 で、既存の解析と同じ。
