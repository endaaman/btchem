# 追加公開データセット調査（Fig4/5 補強用）

調査日: 2026-10-12。`,docs/strategy_20261012.md` で既に確保・評価済みのもの（GSE222752 / GSE238244 /
GSE205237 / GSE296757 / GSE289491 / GSE276391 / NIHMS1776347 / PRJNA1009097）は再評価していない。

## 方法

- GEO: E-utilities（`esearch db=gds` → `esummary`）で検索し、候補ごとに FTP の
  `GSExxxxxx_family.soft.gz` を取得して読んだ（Series の summary / overall_design / supplementary と、
  全 Sample の characteristics を集計）。下表の種・性別・組織・処置・n・ファイル名はすべて SOFT の記載から取ったもの。
  SOFT に書かれていない項目は「記載なし」とし、推測では埋めていない。
- ArrayExpress/BioStudies: `https://www.ebi.ac.uk/biostudies/api/v1/...` で検索し、study JSON の記載を読んだ。
- NCBI BioProject（GEO 外の SRA のみのデータを探すため）: `esearch db=bioproject`。
- MSigDB: gene set のページ（`gsea-msigdb.org/gsea/msigdb/{human,mouse}/geneset/<NAME>.html`）が存在するかを確認した。
- 評価: ◎ = Fig4/5 に直接使える、○ = 補助パネル・Supplementary・検証用に使える、△ = 参照程度（組織・性別・n・
  プラットフォームのどれかが弱い）、✕ = 使えない（見た結果、目的に合わなかった）。

## Fig4/5 に採用を勧める追加データ 上位 5 つ

1. **GSE141595（＋GSE141610）** — ヒトの骨細胞濃縮骨生検で、閉経前（n=15）と閉経後（n=15）を比べられ、denosumab 群（n=15）もある。
   4A のヒト補助パネルにできる。さらに Fig5 の議論「臨床で止められるのは RANKL だけ」について、denosumab で
   閉経後の骨細胞側の何が戻り、何が戻らないかをデータで示せる。若年群は処理バッチが違うので、SRA から揃え直すことを推奨する。
2. **GSE72815** — ヒトの腸骨生検で、若年（19）/ 高齢（19）/ 高齢＋E（20）。GSE222752（OVX / OVX+ERT）とデザインが
   対応しているので、「OVX で変わり、ERT で戻る」遺伝子がヒトでも「加齢（閉経後）で変わり、E 補充で戻る」かを示せる。counts あり。
3. **GSE276529** — ヒト女性の GIOP 皮質骨（4 vs 5）。GSE276391 と同じ論文のヒト版で、4C をマウスとヒトの 2 段にできる。counts あり。
4. **GSE296758** — 雌の LepR+ 骨髄 MSPC で、臨床に近い Dox 5 mg/kg × 4 サイクルの 8 週後（n=4/4）。4B の本命 GSE205237 は
   雄で単回投与なので、性別と投与法の弱点を補える。counts あり。
5. **GSE66205（＋GSE66204）** — 雌マウスの乳がん骨転移（E0771 / MDA-MB-231）で、骨側の骨芽細胞と内皮を bulk で取ったもの（n=3/3）。
   Fig5 で「閉経 × 化療 × ステロイドの重なり」が「実際の骨転移 niche で変わる遺伝子」とどれだけ重なるかを見る参照集合になる。
   ER+ 骨転移 niche マクロファージの GSE263383、niche マクロファージ bulk の GSE270982 は次点。

次点: GSE30159（ヒトのクッシング症候群の骨生検、術前後のペア）、GSE68303（OVX の腰椎、3 系統）、
GSE208289（化療 → 肺の転移 niche。臓器特異性の対照）、GSE276370（転移で骨細胞死が起きる骨髄除去骨）。
