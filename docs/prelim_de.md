## 結論（先に）

- **A（OVX vs Sham, 皮質骨, GSE222752）はほぼ何も出ない**: |log2FC| ≥ 1 かつ padj < 0.05 の DEG は 5 個だけ（上昇 2 / 低下 3）。
  中身は B 細胞系（Cd79a, Cd19, Ms4a1, Vpreb3）の上昇と ER 標的遺伝子（Greb1）の低下で、OVX が効いていること自体は確認できる。
  ただし炎症・破骨パネル（Tnfsf11, Il6, Tnf …）は 1 つも有意にならない。Hallmark GSEA では炎症系は Sham 側に寄る
  （Inflammatory Response NES −1.76, IL-6/JAK/STAT3 NES −1.77、いずれも FDR 0.002）。**閉経で炎症が上がる、とはこのデータからは言えない。**
- **B（Dox vs Vehicle, GSE205237）もほぼ何も出ない**: DEG 9 個。上がったのは脂肪細胞・薬物代謝系（Cyp2e1, Cfd, Cilp）、下がったのは
  マクロファージ・B 細胞系（Timd4, Cd163, Ig 遺伝子）。アポトーシス・老化パネルは**どれも有意でない**（Cdkn2a は +0.63, padj 0.96）。
  GSEA ではむしろ TNF-α/NF-κB と Inflammatory Response が Dox で低下（NES −2.17 / −1.84）。補助の GSE296757（骨芽細胞、Dox 4 回）も
  DEG 11 個、パネルは全滅。Hallmark Apoptosis だけは NES +1.44（FDR 0.064）で、境界的。
- **C（DEX vs Vehicle, GSE276391）は大きく動く**: DEG 1,114 個。パネルでは炎症・破骨系が上昇（Tnf +1.23, Il1b +0.80, S100a9 +1.27,
  Mmp9 +0.97、いずれも padj < 0.05）、**OPG（Tnfrsf11b）が低下（−1.05）**（RANKL/OPG 比の上昇で、既知の GC 作用と矛盾しない）、
  Sost / Dkk1 / Cdkn1a は低下。**アポトーシス系は Bak1 の +0.30（padj 0.079）だけで、Fas / Casp3 / Bax / Trp53 は動かない。**
  Hallmark では IL-6/JAK/STAT3（NES +2.15）と Inflammatory Response（+1.75）が上がり、Apoptosis（−1.30, FDR 0.11）と p53（−1.34）はむしろ下がる方向。
- **清水仮説（閉経 = 炎症/破骨、化療 + ステロイド = アポトーシス）は、主 3 データセットからは支持されない。** 出た結果を逆にすると
  「ステロイドで炎症・破骨方向」「閉経・化療では骨組織の転写変化は小さい」。アポトーシス因子が出たとは言えない。
- 3 contrast の DEG の重なりはほぼ空（strict 閾値で A∩B∩C = 0、B∩C = Cyp2e1 の 1 個）。log2FC の相関も弱い（Spearman ρ: A–B −0.03, A–C −0.05, B–C −0.19）。
- 加齢（清水案①、2.5 y vs 2 mo、♂）は炎症（Il1b +1.11, Tnf +1.36, S100a8/9）とアポトーシス（Fasl +1.44, Pmaip1 +1.14, Bbc3 +0.72, Bak1 +0.50, Bcl2 +0.70）
  の両方が有意に上がる唯一のデータ。ただし RANKL（Tnfsf11）は −1.30 で低下、雄。

## 処理手順

1. `prelim/prepare.py`: 補足ファイル → 遺伝子シンボル単位の整数 counts（`data/seq/<GSE>/counts.tsv.gz`）と `samples.csv`。
   - Ensembl → symbol は GSE276391 だけ必要。GTF もネットも使わず、GEO 内の対応表（GSE205237 の GENCODE M23 の id/name 列、
     NIHMS tS1 で補完）で作った（`data/seq/annot/ensembl2symbol.csv`）。発現のある ID のうち対応なしは 297 個で、Ensembl ID のまま残した。
     （BioMart は gseapy 経由・直接とも疎通せず。）
   - 同一シンボルは合算。RSEM / Partek の非整数 counts は四捨五入。
   - GSE222752 の counts は**全値が偶数**（ペアエンドの両 mate を数えている）ので /2 して fragment 単位に戻した。
2. `prelim/de.py`: 比較する 2 群のサンプルだけを取り出して pydeseq2 0.5.4（`~ cond`、GSE296757 は `~ batch + cond`）。LFC shrink なし（MLE）。
   低発現フィルタは edgeR filterByExpr の既定値に準拠（CPM ≥ 10/中央値ライブラリサイズ[M] を満たすサンプルが小さい方の群の n 以上、かつ合計 ≥ 15）。
   当初の「全サンプル合計 ≥ 10」だけでは GSE276391 で低カウントの背景遺伝子（Olfr, Gm…）が DEX 側で一斉に上がる artefact が強く出たため変更した（全 contrast 共通）。
3. `prelim/volcano.py`: 基本閾値 |log2FC| ≥ 1 かつ padj < 0.05。注目遺伝子パネル（`prelim/genes.py`、事前定義）を白抜き丸で全点表示し、padj < 0.1 のものにラベル。
4. `prelim/enrich.py`: DEG（up/down 別）を Enrichr ライブラリ（GO_BP_2023, KEGG_2019_Mouse, MSigDB_Hallmark_2020）で ORA。
   背景は各 contrast で検定した全遺伝子（gseapy.enrich のローカル超幾何検定）。DEG < 10 なら padj < 0.1 & |log2FC| ≥ 0.585 に緩めて実施し、閾値を出力に残した。
   加えて Wald 統計量で順位付けした Hallmark prerank GSEA（1,000 perm）。
5. `prelim/overlap.py`: 主 3 contrast の DEG 集合の重なり（3 閾値 × up/down）、log2FC 散布と相関、全 contrast の Hallmark NES ヒートマップ。
6. `prelim/qc.py`: データセットごとの PCA と組成マーカー（骨細胞・骨芽・破骨・骨髄/血液・筋・性別・GC 応答・ER 標的）。

## 重なり（主 3 contrast: A_OVX_cort / B_Dox / C_DEX）

- 3 つすべてで検定された遺伝子 12,048。
- strict（padj<0.05, abs(lfc)≥1）: A 2↑/3↓, B 3↑/6↓, C 518↑/596↓。共通は B∩C の **Cyp2e1↑ 1 個のみ**、A∩B∩C = 0。
- lenient（padj<0.1, abs(lfc)≥0.585）: B∩C↑ = Cfd, Cyp2e1, Cyp2f2、A∩C↓ = Pi15。
- nominal（p<0.01, abs(lfc)≥0.585、補正なし・探索用）: B∩C↑ 6（Cfd, Cidec, Cyp2e1, Cyp2f2, Acvr1c, Cyb561 = **骨髄脂肪細胞**系）、A∩C↓ 8（Klhl38, Synpo2, Fbxo32, Pdk4, Pgm5 … = **骨格筋**系、混入量の差と思われる）。
- log2FC 相関（Spearman）: A–B −0.03, A–C −0.05, B–C −0.19。同方向の共通シグネチャは見えない。
- パスウェイ（Hallmark NES, `out/prelim/overlap/hallmark_nes.png`）: 3 つで同方向かつ有意なのは Myogenesis↓ と EMT↓ 程度（A の EMT は↑）で、これらは筋・結合組織の混入量の差を強く疑う。
  炎症系（Inflammatory Response / IL-6 / TNF-α）は A↓・B↓・C↑ でばらばら。

## 問題点・注意

1. **組織組成（筋・骨髄・血液の混入）の差がシグナルを支配している**（`out/prelim/qc/markers.csv`）。皮質骨サンプルでも Acta1/Myh4/Ckm が 100 倍近くばらつき、
   ほぼ全 contrast で Myogenesis / EMT が最上位に来る。GSE238244（脛骨丸ごと）は筋が最大成分で、骨細胞マーカー（Sost, Dmp1）が他の 1/50 程度しかない → 骨細胞のデータとしては不適。
2. **GSE276391 の背景リード**: 嗅覚受容体（Olfr/Vmn）の CPM が他データの 10〜100 倍（gDNA 混入か、total RNA pico キット由来）で、しかも **DEX 群で高い**（DEX ctrl 中央値 ~1,600 vs vehicle ~800）。
   フィルタ強化後も C_DEX の上昇 DEG の約 1/3 が Olfr/Gm 系。背景指標を共変量に入れた C_DEX_bgadj でもパネルの結論（Tnf/Il1b/S100a9/Mmp9↑, OPG↓）は変わらない。
   C_DEX_load の上昇 2,847 個はこの artefact の寄与が大きく（DEX_Load_4 の背景が突出）、信用しない。
3. **GSE276391 の列名と SOFT の不一致**: counts の Vehicle 列は `_1,2,4,5,6`、SOFT は `_1..5`。群内の番号順で GSM に対応させた（群の割り当てには影響しない）。
4. **GSE296757 の群は 5 vs 3**（依頼文の 4/4 ではない）。GSM8975970（S1_D1）は title / library 名が DOX、treatment 欄が PBS と食い違う。title を採って DOX 扱い。S1_C3 と S1_D1 は PCA で外れ。
5. **GSE222752**: 各サンプルが 2 匹のプール、counts は mate 二重計数（/2 で補正済み）。海綿骨サンプルは群内でほぼ同一（PCA で 3 点が重なる）で、技術的反復に近い → 海綿骨の DEG 数（OVX vs Sham 116）は過大評価の可能性。
   皮質骨は群内のばらつきが大きく（筋混入）、n=3 では検出力がない。
6. **GSE205237**: SOFT の assembly が "GRCh38" と書かれているがマウス（GENCODE M23 = GRCm38）。脛骨+大腿骨でも筋・血液が多く、AL5833 が PCA で外れ（筋が少ない）。群は PCA で分離しない。
7. 性別: GSE222752 / GSE238244 / GSE296757 は ♀、GSE205237 / GSE276391 / NIHMS は ♂（Xist / Ddx3y で確認、記載と一致）。軸ごとに性が違う。
8. volcano の x 軸は abs(log2FC) の 99.9 パーセンタイルで切っており、範囲外の点は描かれていない（予備図のため）。

## Fig4 本番に向けた推奨

1. **4C は GSE276391 C_DEX（DEX control vs vehicle control）でよい。** 出るものは「炎症（Tnf, Il1b, S100a9）・Mmp9 上昇と OPG 低下＝破骨細胞誘導方向」。
   アポトーシスは出ていないので、そう書く。背景リード artefact の件は Methods に一文入れ、感度分析（bg 補正）でパネル結果が不変であることを添える。
2. **4A は OVX 単独では成立しない。** 選択肢は (a) A_OVX_cort をそのまま載せ「閉経モデル皮質骨の転写変化は小さい」と書く、
   (b) 清水案①の加齢（Age_2.5y）を 4A に回す——炎症・アポトーシスともに出るが雄なので「閉経」ではなく「加齢」と書く、(c) PRJNA1009097（osteocyte-enriched OVX, SRA）をアライメントして試す。
   ken / 清水の判断が要る。私見では (b) を主、OVX を補助（ER 標的低下で OVX が効いていることは示せる）。ERT 群は向きが逆で薬理量なので Fig には使わない方が安全。
3. **4B は GSE205237 単独ではほぼ空。** Dox 単回 30 日後では骨組織の転写変化は小さく、アポトーシス・老化パネルも出ない。GSE296757（骨芽細胞、反復投与）も弱い（Hallmark Apoptosis が境界的に上がるのみ）。
   化療の軸は「骨に持続的な転写変化を残さない」が現時点の結果。GSE289491（scRNA, Dox 96 h）で急性期を見るか、文献ベースに切り替えるかを相談したい。
4. 閾値は **padj < 0.05 かつ abs(log2FC) ≥ 1 を据え置き**を推奨。padj < 0.1 に緩めても A/B は変わらず、C は十分出るので、閾値を動かす理由がない。
5. 重なり（Fig5）を遺伝子レベルで描くのは現状不可能（共通 DEG ≈ 0）。描くならパスウェイレベル（Hallmark NES ヒートマップ）だが、その場合も組織組成（筋・骨髄）の補正が先。
   本番前に、組成マーカーを共変量にするか、CIBERSORT 系のデコンボリューションで組成差を見積もる処理を入れることを推奨。
