## 結論（先に）

1. **案2 の番号は GSE235942 が正しい。** 依頼資料本文の「GSE23592」はニワトリの熱ストレスのマイクロアレイ（脳・肝・筋）で、無関係です（URL 側の番号が正）。
2. **案2（GSE235942、雌の脛骨 22 か月 vs 6 か月、3 vs 4）は、「加齢で炎症が上がる」を支えない。むしろ逆向き。ただしこれは組成の差でほぼ説明でき、生物学的な結論には使えない。**
   - 素のままでは炎症反応 NES −2.05、IFN-α −2.52、IFN-γ −2.37、アポトーシス −1.46（いずれも FDR < 0.05）と、すべて ↓。
   - 22 か月の雌は、骨に残った血液（Hbb-bs / Hba-a1）が 6 か月の約 1/16、白血球（Ptprc）が約 1/2、付着した筋が約 3 倍。骨髄の残り方が群で完全に分かれている。
     「炎症 ↓」も「増殖（E2F −3.47）↓」も、骨髄の細胞が少ないことの写しと見るのが自然です。
   - 組成を共変量に入れると炎症は +1.13（有意でない）、TNF-α +1.47・アポトーシス +1.47・IL6/JAK/STAT3 +1.62（FDR < 0.05）と向きが反転する。ただし血液の量が群と完全に重なっているので、この補正は外挿になる。
     実際、補正版の上位 DEG は Chit1 +11.9、Ly6k +11.8、免疫グロブリン ±10 と不安定で、GO の上位は「止血・血小板・赤血球分化」でした。**補正版も信用できない**ので、どちらの向きも主張には使いません。
   - 組成に左右されにくい個別の遺伝子では、**老化マーカー p16（*Cdkn2a*）+1.33（padj 0.001）と、加齢・p53 標的の *Eda2r* +2.02 が上がる**。p21（*Cdkn1a*）+0.43（padj 0.09）。
     アポトーシスの実行因子は上がらない（*Casp3* −0.90、*Bcl2* −0.59、*Fas* ±0）。
3. **同じデータの雄（22 vs 6 か月、10 vs 5、依頼外）では、炎症と破骨支持が上がり、組成を補正しても残る。**
   - 炎症反応 +1.59、破骨分化の正の制御 +1.92、骨吸収 +2.28（いずれも FDR < 0.05）。補正版でも炎症反応 +2.01、IFN-α +2.76、SenMayo +1.55、アポトーシス +1.49。p16 +1.99（padj 0.006）。
   - 同じ施設・同じ処理で、雄は炎症 ↑、雌は炎症 ↓ に見える。ただし雌は組成が大きく違い、しかも原著論文は雄だけを解析していて、雌のサンプルは GEO にあるだけなので、**性差とは言えない**。
   - 雄の 22 vs 6 か月では骨形成 +1.82・ECM +2.10 と ↑ で、現行 4A（Kaya 2022、30 vs 2 か月）の骨形成 −2.4・ECM −3.4 と逆でした。
     Kaya の若齢は 2 か月の成長期なので、**現行 4A の「骨形成・ECM ↓」の多くは成長期との差**とみられます（TMS の雌で見た 1–3 か月の効果と同じ。`docs/prelim_aging_f.md` §3）。
4. **案3（GSE255653、LepR+ 骨髄間質 18 か月 vs 3 か月、3 vs 3）では、骨形成・ECM・血管・脂肪の niche 軸の ↓ がはっきり出る。これは Dox 反復後の LepR+ 間質と同じ向き。**
   - 骨化 −2.22、NABA core matrisome −2.63（いずれも FDR < 0.05）、血管新生 −1.51（FDR < 0.25）。
     個別の遺伝子では *Bglap* −4.43、*Sp7* −1.10、*Spp1* −1.65、*Igf1* −1.45、*Adipoq* −1.02、*Vcam1* −1.01（いずれも padj < 0.05）。
   - 血球・内皮で高い遺伝子 1,904 個を抜いても残る（骨化 −2.50、matrisome −2.83、血管新生 −1.70。いずれも FDR < 0.05）。
   - NES は雌雄の LepR+ / CAR の加齢（GSE130885 +0.30、GSE133922 +0.41）、Dox×4 / ×1 の LepR+ MSPC（+0.42 / +0.55）、現行 4A（+0.73）と同じ向き。
     **「加齢した間質と Dox を受けた間質で、骨形成 niche が同じように下がる」**という v2 資料の結論（`docs/prelim_niche.md` 結論 1）を、独立データでもう 1 本支えます。
5. **案3 の「炎症 ↑」は使えない。老齢の 3 例はすべて血球が混入している。**
   - 素のままでは炎症反応 +1.68、IFN-γ +1.56、アポトーシス +1.50、骨髄系の活性化 +2.30 と上がり、*Il1b* +5.65、*Tnf* +4.94、*Il6* +4.10 も大きく上がる。
   - しかし老齢の 3 例すべてに形質細胞の転写物（*Igkc* がリードの 1.8–11%、*Jchain* ↑）があり、2 例には肥満細胞・好塩基球（*Cpa3*, *Fcer1a*）と白血球・内皮（*Ptprc*, *Pecam1*）もある。
     **サイトカインの上昇はこの 2 例だけ**で、混入の少ない 3 例目は若齢と同程度でした（*Il1b* 5.7 vs 0.3–2.3 CPM、*Tnf* 3.2 vs 0.5–1.4、*Il6* 93 vs 28–60）。
     DEG の上位（*Cytip*, *Itgal*, *Vav1*, *Syk*, *Rac2*）も白血球の遺伝子で、GO の上位も「白血球の脱顆粒・肥満細胞の活性化・B 細胞受容体」です。
     CD45−TER119−CD31−LEPR+ のゲートでは、CD45 が低い形質細胞が抜けきらない（老齢の骨髄では形質細胞が増える）ためと考えます。
   - 混入しうる遺伝子を抜くと、炎症は +1.58（FDR < 0.25）に弱まり、**SenMayo は +1.24 から −1.82（FDR < 0.05）へ反転**しました。p21（*Cdkn1a*）は −1.32（padj < 0.001）と ↓。p16 は検出限界以下。
6. **Figure 4A の主張（加齢で炎症・アポトーシス・老化）への答え**:
   - **炎症**: 2 本とも「支える」とは言えない。雌の骨は組成で逆向き、MSC は混入で上向き。同じデータの雄の骨（組成補正後も ↑）が、既存の雄の加齢骨（Kaya、雄 CAR）の独立した再現になる。
   - **アポトーシス**: 支えない。gene set の動きは組成・混入と同じ向きで、実行因子（*Casp3/8/9*, *Bax*, *Bcl2*）は雌の骨でむしろ ↓。
   - **老化**: **p16（*Cdkn2a*）↑ は雌雄の脛骨（GSE235942）と現行 4A（Kaya +1.85）で一致する唯一の老化マーカー**。ただし SenMayo などの gene set は向きが割れていて、間質（MSC）では ↓。
   - **niche（骨形成・ECM・血管）↓**: 案3 は頑健に支え、Dox の LepR+ 間質とも一致する。4A を「骨環境全体」に広げる方針には、こちらの方が使える。
7. **推奨**: 4A の本編を案2（雌の骨）で置き換えるのは勧めません（組成が交絡、雌は原著で未解析）。案3 は「加齢した LepR+ 間質で骨形成 niche が下がる」パネルとしてなら使えます。
   ただし炎症の行は混入の注記なしに出せません。雌雄の p16 ↑ は、現行 4A の補強として Supplementary か本文で使えます。

### GSE235942 — 若齢・老齢マウスの脛骨（後肢懸垂つき）（案2）

| 項目 | 内容 |
|---|---|
| 出典 | Meas SJ et al., *Bone* 2024;179:116973（PMID 37996046、PMC11651238） |
| 動物 | マウス C57BL/6J、**雌と雄**（雌は GEO にだけあり、論文では解析されていない。下記） |
| 組織 | 左脛骨、骨髄を洗い流したもの（骨幹だけでなく骨端・成長板を含む脛骨全体） |
| 群（GEO） | 雌 22 か月 対照 3 匹 / 雌 6 か月 対照 4 匹 / 雄 22 か月 対照 10 匹・後肢懸垂 3 匹 / 雄 6 か月 対照 5 匹・後肢懸垂 5 匹（計 30） |
| 処置 | 後肢懸垂（tail suspension で後肢を浮かせる廃用モデル）3 週間。対照は同じケージで懸垂なし |
| 測定 | bulk RNA-seq（Illumina stranded mRNA、NextSeq 2000 paired-end）。GEO に遺伝子ごとの整数カウント（BioJupies = kallisto）あり |
| ファイル | `data/seq/GSE235942/GSE235942_raw_counts.txt.gz`、SOFT、作った `counts.tsv.gz` / `samples.csv` |

**どんな実験か.** 加齢による骨量減少と、廃用（寝たきり・宇宙飛行）による骨量減少が似ているかを比べた研究です。
6 か月（ヒトの 30 歳前後）と 22 か月（60 歳前後）のマウスに後肢懸垂を 3 週間行い、μCT・骨強度と、骨の遺伝子発現を比べています。
骨は液体窒素中で砕き、Trizol で RNA を取っています。月齢は論文では介入開始時の月齢で、採取はその約 3 週後です。

**依頼との対応.** 依頼の「Female, 22-month-old, control 1–3 vs Female, 6-month-old, control 1–4」はこのデータの雌の対照群そのものです。依頼どおり**対照どうしだけ**を比べました。
ただし、「皮質骨」とあるのは正確には「骨髄を洗い流した脛骨全体」です。皮質骨が中心ですが、海綿骨・成長板・付着した筋も入ります。

**注意点.**
- 論文の方法には「**この研究では雄だけを使った**」と明記されていて、雌のサンプルは論文に出てきません。GEO の概要には雌雄とあります。雌の飼育条件・採取時期が雄と同じかは確認できません。雌は後肢懸垂群が登録されておらず、対照だけです。
- 性別のラベルは発現で確認しました。Y 染色体の遺伝子（*Ddx3y*, *Eif2s3y*, *Uty*）が、雌 7 例はすべてほぼ 0、雄 23 例はすべて陽性で、食い違いはありません。
- **雌の 22 か月と 6 か月で、骨に残った骨髄と付着した筋の量が大きく違います**（`out/prelim/aging2/qc/composition_GSE235942.csv`、`sample_scores.png` C）。
  血液（*Hbb-bs*/*Hba-a1* の log2 CPM）は 22 か月 10.5 / 6 か月 14.5（約 16 倍の差）、白血球（*Ptprc*）7.1 / 8.0、筋（*Acta1*/*Ckm*/*Myh4*）13.4 / 11.9 でした。
  雄では血液 13.2 / 14.3、筋 12.9 / 12.8 と差は小さい。老齢の雌の骨髄が脂肪に置き換わって洗い流し後に残りにくい、という生物学的な差の可能性もありますが、bulk ではそれ自体が「組成の差」として全体の結果を動かします。

**評価: △（雌）/ ○（雄、依頼外）.** 雌の比較は組成が群と完全に重なっていて、gene set の向きを主張に使えません。p16 ↑ のような個別の遺伝子だけが使えます。
雄の比較は n = 10 vs 5 と大きく、組成を補正しても炎症 ↑ が残るので、現行 4A（雄）の独立した再現として Supplementary に使えます。

**ほかの群（後肢懸垂）について.** 雄の 6 か月・22 か月にだけ後肢懸垂 3 週の群があります。これは廃用（荷重がかからないこと）の効果で、加齢の比較には使えません。
- 6 か月: 後肢懸垂 5 vs 対照 5 で DEG 3 / 2 個。gene set では増殖 ↑（E2F +2.71）、OXPHOS ↓（−3.48）、脂肪 ↓（−2.19）、筋 ↓（−1.90）で、骨髄の活性化と筋萎縮の写しに見えます。
- 22 か月: 後肢懸垂 3 vs 対照 10 で DEG 0 / 2 個。gene set では SenMayo +1.69、p53 +1.62、アポトーシス +1.81、ECM +2.28（いずれも FDR < 0.05）。
  論文の「老齢では廃用で老化パスウェイは変わらない」（IPA）とは方法が違うので単純には比べられず、n = 3 なので参考値です。
- 意見: 「加齢 × 廃用」の 2-hit のデータとしては面白いのですが、本研究の「加齢 × 化療」とは別の話で、雄だけです。Figure 4 には使わない方がよいと考えます。

### GSE255653 — 若齢・老齢マウスの骨髄 LepR+ 間質（Thbs1 欠損つき）（案3）

| 項目 | 内容 |
|---|---|
| 出典 | Ramalingam P et al., *Sci Immunol* 2025;10:eads1556（PMID 39752538、PMC12068530）。SuperSeries GSE255656 の dataset 4 |
| 動物 | マウス C57BL/6J（対照は NIA / Jackson から入手）。Thbs1 欠損は B6.129S2-Thbs1tm1Hyn/J |
| 性別 | GEO・論文に**このデータの性別の記載なし**（論文は「雌雄を使い、群間で比をそろえた」とだけ書いている）。発現から**全 9 例とも雌と推定**（下記） |
| 細胞 | 長管骨の骨髄から FACS で分取した **LepR+ 間質**（CD45− TER119− CD31− LEPR+）。採取 10 分前に抗 VE-cadherin 抗体を静注して血管内皮を標識 |
| 群 | 若齢 3 か月 対照 3 匹 / 老齢 18 か月 対照 3 匹 / 老齢 18 か月 Thbs1 欠損 3 匹 |
| 測定 | 低入力 bulk RNA-seq（2 ng の RNA、SMART-Seq v4、NovaSeq、1 例あたり約 5,000 万 paired-end リード） |
| ファイル | GEO には **FPKM しかない**（`GSE255653_FPKM_Subseries_4.txt.gz`）。カウントは下記の方法で復元（`data/seq/GSE255653/counts.tsv.gz`） |

**どんな実験か.** 加齢に伴う慢性炎症（inflammaging）で造血幹細胞が衰える仕組みを調べ、トロンボスポンジン-1（Thbs1）を消すと防げる、と示した研究です。
このサブシリーズは「老齢の Thbs1 欠損マウスの間質がどう変わるか」を見るためのもので、若齢・老齢の対照は比較の基準として置かれています。
論文の補足では、老齢の欠損マウスの LepR+ 間質で WNT/NOTCH（骨形成側）↑、*Tnf*・*Il1b* ↓ と報告されています（fig. S14）。

**依頼との対応.** 依頼の「Young_Control_MSC_1–3 vs Aged_Control_MSC_1–3」をそのまま比べました。「MSC」は培養した間葉系幹細胞ではなく、**生体から直接分取した LepR+ 間質（CAR 細胞と同じ系統）**です。

**性別の確かめ方.** Y 染色体の遺伝子（*Ddx3y*, *Eif2s3y*, *Uty*, *Kdm5d*）が 9 例すべてで 0 でした。一方、*Xist* は 9 例すべてで発現していました（log2 CPM 7.7–9.5）。

**カウントの復元（GEO に生カウントが無いため）.** 原著の処理は DEE2 ワークフロー（STAR で GRCm38 に整列し、遺伝子ごとにリードを数える）→ edgeR で FPKM です。
FPKM = カウント × 10⁹ /（遺伝子長 × ライブラリサイズ）なので、遺伝子長とライブラリサイズが分かればカウントに戻せます。
- 遺伝子長は DEE2 の遺伝子情報の "merged"（全エクソンを合わせた長さ）でした。Σ FPKM × 長さ が 0.99 × 10⁹ になり、ほかの長さの定義（0.45–0.83 × 10⁹）では合いません。
- ライブラリサイズは、サンプルごとに「短い遺伝子のカウントが整数になる値」を探して決めました（1,780 万–2,760 万）。対照 6 例では SRA のリード対の数の 69–77% で、STAR の集計として妥当です（欠損群の 1 例だけ 16% で、SRA 側のリード数が 1 億 1 千万と他の 3–4 倍）。
- 検証として、FPKM の丸め誤差が小さい遺伝子（1 例あたり 930–1,840 個）の **99.3–99.9% で、復元値と整数の差が 0.1 未満**でした（偶然なら約 20%）。
  したがって、復元したカウントは元の整数カウントと実質的に同じで、DESeq2 にかけて問題ありません（`out/prelim/aging2/qc/GSE255653_reconstruction.csv`）。
- 遺伝子名を長さに対応づけられなかった 104 遺伝子（うち FPKM > 1 は 8 個。*Atp5md* など改名された遺伝子）は落としました。

**注意点（重要）.** 老齢の対照 3 例は、LepR+ 間質以外の細胞の転写物を含みます（`out/prelim/aging2/markers_GSE255653.csv`、`sample_scores.png` D）。

| 混入の指標（CPM） | 若齢 1–3 | 老齢 1 | 老齢 2 | 老齢 3 |
|---|---|---|---|---|
| *Igkc*（形質細胞・B 細胞） | 19–790 | 92,683 | 17,675 | 112,572 |
| *Jchain*（形質細胞） | 7–90 | 2,794 | 991 | 2,366 |
| *Cpa3* / *Fcer1a*（肥満細胞・好塩基球） | 1–2 | 317 / 444 | 315 / 489 | 17 / 29 |
| *Ptprc*（白血球） | 0.4–1.1 | 55 | 76 | 7 |
| *Pecam1*（内皮） | 0.3–0.6 | 59 | 73 | 13 |
| *Il1b* / *Tnf* / *Il6* | 0.3–2.3 / 0.5–1.4 / 28–60 | 55 / 19 / 709 | 117 / 41 / 1,307 | 6 / 3 / 93 |

形質細胞は CD45 の発現が低いので、CD45− のゲートを通りやすく、老齢の骨髄では数も増えます。
老齢の欠損マウスの 1 例（Aged_TSPKO_MSC_1）は混入がほぼ無く、欠損群の「炎症 ↓」にも純度の差が混じっています。

**評価: ○（niche 軸）/ ×（炎症）.** 骨形成・ECM・血管・脂肪の ↓ は、混入しうる遺伝子を抜いても残り、ほかの加齢の LepR+/CAR や Dox の LepR+ 間質とそろうので使えます。
炎症・サイトカインの ↑ は混入で説明できるので、主張には使えません。n = 3 vs 3 で、性別は推定です。

## 2. 方法（既存と同じ流儀）

- DE: pydeseq2（`prelim/aging_f/deutil.py` = `prelim/de.py` と同じ低発現フィルタ、MLE、shrink なし）。閾値は padj < 0.05 かつ |log2FC| ≥ 1。
- 組成補正版（GSE235942）: `~ muscle + blood + cond`。muscle = *Acta1*/*Ckm*/*Myh4*、blood = *Hbb-bs*/*Hba-a1* の log2 CPM 平均を、比較に使うサンプルの中で z 化（`prelim/chemo2/gsea.py` の B_Dox_compadj と同じ作り方）。
- GSEA: `prelim/chemo2/genesets.collection()`（Hallmark 50 + MSigDB M2/M5 17 + 手製 5 = 72 set、MSigDB 2025.1.Mm）。Wald 統計量で prerank、gseapy 1000 perm、seed 0、min 4、max 1000。
  GO BP 全体（size 15–500）も主な contrast で回した（探索用、`gsea/gobp_*.csv`）。

## 5. 依頼資料の問いへの答え

- **案2（GSE23592 / GSE235942）**: 正しい番号は GSE235942。雌 22 か月 vs 6 か月の対照どうしを比べました。
  **炎症・アポトーシスは上がらず、むしろ下がる。ただし骨髄の残り方が群で 16 倍違い、組成で説明できる。補正すると向きが反転するが、補正も外挿で信用できない。**
  確かに言えるのは p16（*Cdkn2a*）↑ と *Eda2r* ↑ だけです。同じデータの雄（依頼外）では、炎症 ↑・破骨支持 ↑ が組成補正後も残ります。
- **案3（GSE255653）**: 性別は記載なし、発現から全例雌と推定。細胞は生体から FACS で取った LepR+ 間質（CD45−TER119−CD31−LEPR+）で、3 か月 vs 18 か月。GEO には FPKM しか無く、カウントを復元して解析しました（復元の精度は 99% 以上で整数に一致）。
  **骨形成・ECM・血管の ↓ は頑健で、Dox の LepR+ 間質とそろう。炎症 ↑ は混入（形質細胞・肥満細胞・白血球）によるもので、使えない。老化（SenMayo）は混入を除くと ↓、p21 ↓。**
- **Figure 4A の「炎症・アポトーシス・老化」を支えるか**: どちらのデータも、そのままでは支えません。
  使えるのは (1) p16 ↑（雌雄の脛骨と現行 4A で一致）、(2) 間質の niche 軸 ↓（加齢と Dox で一致）、(3) 同じデータの雄の炎症 ↑（組成補正後も残る、現行 4A の再現）の 3 点です。
  「骨全体の環境に広げる」方針なら、(2) を軸に「加齢した間質は骨形成 niche を失い、Dox も同じ方向に押す」と描く方が、データに素直です。

## 6. 言えること / 言えないこと

**言えること**
- GSE235942 の雌の 22 か月と 6 か月の差は、骨に残った骨髄（血液 16 倍、白血球 2 倍）と付着筋（3 倍）の差に強く影響されている（組成の数値はそのまま書ける）。
- 雌雄の脛骨で p16（*Cdkn2a*）が上がる（雌 +1.33、雄 +1.99、どちらも padj < 0.01）。現行 4A（雄 30 か月）でも +1.85 で、3 データで同じ向き。
- 雄の脛骨（22 vs 6 か月、n = 10 vs 5）では、炎症・破骨支持・骨吸収の gene set が上がり、組成を補正しても炎症は残る（+2.01）。
- 老齢（18 か月）の雌の LepR+ 間質では、骨形成・ECM・血管・脂肪の遺伝子群が下がり、*Bglap*・*Sp7*・*Igf1*・*Adipoq* が下がる。血球・内皮で高い遺伝子を除いても残り、既存の加齢 LepR+/CAR、Dox の LepR+ MSPC と同じ向き。
- 現行 4A の「骨形成・ECM ↓」は、若齢側が 2 か月（成長期）であることの影響が大きい。6 か月を基準にした GSE235942 の雄では逆に ↑。

**言えないこと**
- 「雌の骨では加齢で炎症が下がる」「雌雄で炎症の向きが違う（性差）」— 組成の交絡があり、雌は原著で未解析。
- 「加齢した LepR+ 間質で炎症・サイトカインが上がる」— 混入で説明でき、混入の少ない 1 例では上がっていない。
- 「加齢でアポトーシスが上がる」— gene set の動きは組成・混入と同じ向きで、実行因子は動かないか下がる。
- 「加齢で SenMayo（SASP）が上がる」— 雌の骨は ↓ 傾向、間質は混入を除くと ↓、雄の骨だけ ↑（補正後 +1.55）。
- 雌の骨の結果から、閉経（エストロゲン低下）について何か言うこと — ER 標的は動かず、22 か月の雌の内分泌状態は不明。

## 7. Limitation

- GSE235942 の雌は原著で解析されておらず、飼育・採取の条件が雄と同じかを確認できない。n = 3 vs 4。雌の後肢懸垂群は無い。
- 組成補正は、共変量（血液）が群と完全に分離しているため外挿になり、補正版の推定は不安定（上位 DEG に ±10 の log2FC）。素のままの結果も補正版も、gene set の向きは主張に使えない。
- 骨は「骨髄を洗い流した脛骨全体」で、皮質骨だけではない（成長板・海綿骨・筋を含む）。月齢は介入開始時で、採取はその約 3 週後。対照も懸垂用ケージで 3 週飼育されている。
- 時計遺伝子が群で動いており（*Arntl*, *Npas2*）、採取時刻の差が混じっている可能性を否定できない。
- GSE255653 は FPKM からの復元カウント（復元精度は高いが、104 遺伝子を落とした）。n = 3 vs 3。性別は発現からの推定。
- GSE255653 の老齢群は形質細胞・肥満細胞・白血球・内皮の転写物を含み、その程度が 3 例で違う。混入しうる遺伝子の除外は 10x の単一細胞データ由来の定義で、形質細胞・肥満細胞に特有の遺伝子は拾いきれない（除外後も GO の上位に B 細胞受容体系が残る）。
- 18 か月はマウスの「中高年」で、22–30 か月の老齢データとは月齢が違う。低入力（2 ng）の SMART-Seq で、発現量の低い遺伝子（*Cdkn2a* など）は検出できない。
- GSEA の FDR は 72 set のコレクション内で計算している。set は重なるので、NES の相関は独立な検定ではない（記述用）。
