## 結論（先に）

1. **案1 GSE304562 は化療でも加齢でもなく、ステロイド（コルチコステロン）のデータ。** 分化させたマウス骨芽細胞株 MC3T3-E1 に、マウスの内因性グルココルチコイドである
   コルチコステロン 100 nM を 24 時間（各 3 well）。依頼資料には処置が書かれていないので、**清水先生が「4C = ステロイド」のつもりで選んだのかを確認したい**
   （化療後の骨芽細胞を意図していたなら、該当するのは 4B の Blood 論文側の骨芽細胞 bulk〔GSE296757、GSE296761 の一部〕）。
2. **案1 は volcano として成立し、中身は教科書どおりのステロイド作用。** DEG 上昇 270 / 低下 246。GR（グルココルチコイド受容体）標的が 16 個中 15 個上昇（*Fkbp5* +2.47、*Sgk1* +2.74、*Per1* +2.02、*Tsc22d3*/GILZ +1.50）＝薬が効いている陽性対照。
   - 骨形成プログラムの低下: *Runx2* −1.15、*Sp7* −1.34、*Bglap* −1.86、*Ibsp* −1.19、Wnt 系（*Dkk2* −5.6、*Wnt7b* −4.0）。GO ossification −1.60、NABA matrisome −1.70（FDR 0.06–0.07）。
   - **RANKL/OPG 比の上昇**: OPG（*Tnfrsf11b*）−1.08（padj 3e-6）、RANKL（*Tnfsf11*）+1.44（ただし 0.9 → 2.3 CPM と低発現）。
   - **炎症は上げない（むしろ下げる）**: *Ccl2* −2.13、*Mmp9* −1.40。Hallmark inflammatory response +1.00（FDR 0.55）。Hallmark TNF-α/NF-κB +1.71（FDR 0.007）は出るが、leading edge は *Sgk1, Per1, Klf9, Dusp1, Nfkbia* という GR 標的（抗炎症側）。
   - アポトーシスは割れる: Hallmark apoptosis +1.48（FDR 0.041。*Bcl2l11*/Bim +0.80 を含む）だが、抗アポトーシスの *Bcl2l1* +0.84、*Casp3* −0.42、*Bbc3* −0.44。「アポトーシスが起きた」とは書けない。
   - SenMayo +1.56（FDR 0.022）。ただし leading edge は *Serpine1, Igfbp4, Cxcl12, Angptl4, Igfbp7* など GC で誘導される分泌因子が中心。
3. **案2（DEX 脛骨）を骨全体の環境として読み直すと、「炎症の上昇」は好中球・単球が増えた分で、骨芽細胞の大きな減少と B 細胞の減少を伴う。**
   骨髄込みの脛骨を区画マーカーで読むと（DEX − 対照、平均 log2 CPM、BH 補正 Welch P）: **骨芽細胞 −1.65（0.027。*Bglap* −3.2、*Col1a1* −2.3）、骨細胞 −0.63（0.038）、
   破骨細胞 +0.59（0.014）、脂肪細胞 +0.58（0.027）、好中球 +1.52（0.002）、単球/マクロファージ +0.54（0.010）、B 細胞 −1.50（0.027）**。血管内皮・赤血球系・LepR+ 間質は動かない。
   v1 で「炎症・破骨因子の上昇」として見せた *S100a9 / Mmp9 / Tnf* は、10 サンプルで好中球スコアと ρ = 0.92–0.94、OPG は骨芽細胞スコアと ρ = 0.94 で連動する。
   **骨の細胞が炎症を起こしたのではなく、骨髄の細胞構成が骨髄球系に傾き、骨芽細胞が減った**、が正確な読み。これはステロイドの既知の作用（骨形成抑制、好中球増多、B リンパ球減少、骨髄脂肪化）と合う。
4. **案1 と案2 は「骨芽細胞の変化」としては一部だけ並べられる。** 共通するのは **骨形成遺伝子の低下と OPG の低下**（案1 −1.08、案2 −1.05、ヒト GIOP〔GSE276529〕−1.00）。
   全遺伝子の相関は弱く（Wald 統計量 Spearman ρ = 0.09）、モジュールでも両方有意なのは同方向 2 / 逆方向 8（逆は OXPHOS・脂肪酸代謝・myogenesis・apoptosis など、生体側の組成の影響を受ける set）。
   炎症（案1 ↓ / 案2 ↑）とアポトーシス（案1 +1.48 / 案2 −1.46）は向きが逆。
5. **4A / 4B との向き**: 案2（DEX 脛骨）は**マウス加齢骨とほぼ同じ形**（NES ρ 0.87、遺伝子 ρ 0.56）で、Dox × 4 の LepR+ MSPC とも同じ向き（NES 0.53）。一方で**ヒトの閉経後・高齢の生検とは逆向き**（NES ρ −0.48 / −0.58）。
   案1 は 4A・4B のどれともモジュールでほぼ独立（ρ −0.23〜0.28）。SenMayo ↑ だけがヒト閉経後・高齢・in vitro エトポシドと同じ向き。
6. **4C の役割（意見）**: 4C は「化療レジメンに必ず併用されるステロイド（制吐・前投薬のデキサメタゾン）が骨芽細胞と骨の環境に与える作用」を担うのが自然で、
   データが一貫して支えるメッセージは **「骨形成の抑制と OPG の低下（RANKL/OPG 比の上昇）」** に絞るべき。v1 の「ステロイドで炎症・アポトーシス」は書けない。
   構成は **4C 本編 = 案1（in vitro 骨芽細胞、直接作用）、案2 は「骨環境」の読み直し版を Supplementary**（ヒト GIOP の OPG 低下と並べて案1 を生体で裏付ける）を推奨する（§8）。
   10/13 の「DEX は話を混乱させる」は、案2 が加齢骨と同じ形になることが原因で、案1 にはこの問題が無い。

## 1. データセットの説明（清水先生向け、転記可）

### GSE304562 — マウス骨芽細胞株にコルチコステロン（ステロイド）24 時間（10/14 依頼の 4C 案1）

| 項目 | 内容 |
|---|---|
| 出典 | Moor MB et al., *Pflügers Arch* 2026;478(10):81（PMID 42760427、PMC13588846）「High-salt diet modulates endocrine regulation between cortisol and FGF23」 |
| 細胞 | マウス骨芽細胞株 **MC3T3-E1 subclone 4**（新生仔頭蓋冠由来の前骨芽細胞株）。発現上は**雄**（Y 染色体遺伝子 *Ddx3y* 55–66 CPM、*Xist* ≈ 0） |
| 培養 | アスコルビン酸・β-グリセロリン酸で 6 日間骨芽細胞へ分化させた後に処置。継代 4–12 |
| 群 | 溶媒（n = 3）/ コルチコステロン 100 nM 24 時間（n = 3）。GEO の記載では両群とも活性型ビタミン D（カルシトリオール 10 nM）存在下（論文本文には記載なし） |
| 測定 | bulk RNA-seq（Novogene、NovaSeq PE150、1 サンプル 2,100–3,500 万リード対） |
| ファイル | `GSE304562_FPKM_allSamples.txt.gz`（下記の注意）。`data/seq/GSE304562/` |

**どんな実験か.** 食塩を多く摂るとコルチゾールが上がり、骨から出るリン調節ホルモン FGF23 が下がる、という腎臓・内分泌の研究です。
その機序として、骨芽細胞にステロイドを当てると *Fgf23* が下がることを示すために RNA-seq が行われました。骨転移や化療とは関係のない目的の実験です。
コルチコステロンはマウスの体内にある本来のステロイドホルモン（ヒトのコルチゾールにあたる）で、臨床で使うデキサメタゾン（合成ステロイド）とは別の薬です。100 nM は生理的範囲程度の濃度です。

**本研究で何を見たか.** 他のデータと同じ方法（DESeq2、閾値 |log2FC| ≥ 1 かつ調整済み p < 0.05、同じ注目遺伝子パネルと遺伝子セット）で、コルチコステロン群と溶媒群を比べました。

**何が出たか.** DEG は上昇 270 / 低下 246 個で、サンプルは処置で明確に 2 群に分かれます（主成分 1 が 88%）。

- ステロイドが効いている印（GR 標的: *Fkbp5*, *Sgk1*, *Per1*, *Tsc22d3*）がそろって 3–7 倍に上昇。論文の主張（*Fgf23* 低下）も再現（−2.26）。
- 骨をつくる遺伝子が低下: *Runx2* −1.15、*Sp7*（Osterix）−1.34、*Bglap*（オステオカルシン）−1.86、*Ibsp* −1.19。
- **OPG（破骨細胞を抑える因子）が半分に低下（−1.08）**、RANKL はわずかに上昇（+1.44、ただし発現量自体がごく低い）。
- 炎症性サイトカインは上がらず、*Ccl2* −2.13、*Mmp9* −1.40 とむしろ低下（ステロイドの抗炎症作用）。
- アポトーシス関連は、促進側の *Bcl2l11*（Bim）+0.80 と抑制側の *Bcl2l1* +0.84 が両方上がり、*Casp3* は −0.42 と下がる。どちらとも言えません。

**限界.** 生体ではなく培養した細胞株で、1 濃度・24 時間だけの急性の反応です。骨芽細胞以外（骨細胞・破骨細胞・骨髄）は含みません。
n = 3 は同じ株の培養の繰り返しで、個体差ではありません。ステロイドはデキサメタゾンではなくコルチコステロンで、カルシトリオールが両群に入っています。
論文本文は「RNA-seq で *Rankl* と *Opg* が低下」と書いていますが、寄託データから再計算すると *Rankl* は上昇（低発現）、*Opg* は低下でした（本研究の値は寄託データに基づく）。

**ファイルの注意（技術的）.** 補足ファイルは名前が "FPKM" ですが、中身は DESeq2 型の**正規化 counts**でした（各列の値がすべて列内の最小値の整数倍、列和が約 2,000 万）。
最小値で割ると整数の生 counts に誤差 0.0005 以下で戻り（count 1 の遺伝子が各列 1,700–2,100 個）、戻した総数は SRA のリード数の 73–77 %（遺伝子に割り当てられた割合として自然）。
この生 counts を他のデータと同じ DESeq2 にかけています（`data/seq/GSE304562/count_recovery.csv`）。全サンプルで 0 の遺伝子は元のファイルに入っていない（*Sost*, *Dkk1*, *Pparg*, *Adipoq* など）。

**評価: ○〜◎（4C 本編の候補）** 骨芽細胞そのものにステロイドが直接何をするかを、組織の混ざり物なしに示せる唯一のデータです。in vitro であることは Limitation に書きます。

### GSE276391 — DEX 5 日投与マウスの脛骨（現行 4C、10/14 依頼の 4C 案2）

| 項目 | 内容 |
|---|---|
| 出典 | PMID 39641269（ヒト版 GSE276529 と同じ論文） |
| 動物 | マウス**雄** 3 か月 |
| 組織 | 脛骨を丸ごと凍結粉砕（**骨髄込み**） |
| 群 | 溶媒（n = 5）/ デキサメタゾン 1 mg/kg 皮下 5 日（n = 5）。同じ実験に荷重刺激の群があるが使っていない |
| 測定 | bulk RNA-seq（total RNA pico キット） |
| ファイル | `GSE276391_rsem_count.tsv.gz`、`data/seq/GSE276391/` |

**どんな実験か.** ステロイド性骨粗鬆症（GIOP）の研究で、ステロイドが骨の荷重応答をどう変えるかを見たものです。マウスのデキサメタゾン 1 mg/kg は、
体表面積換算でヒトの約 0.08 mg/kg（体重 60 kg で約 5 mg）にあたり、化療の制吐・前投薬で使うデキサメタゾンの 1 回量（数 mg〜十数 mg）と同じ桁です（ただしマウスは 5 日連続）。

**本研究で何を見たか.** v1 では volcano で炎症・破骨因子と OPG を見ました。今回は、骨髄込みの脛骨であることを逆に利用して、
骨芽細胞・骨細胞・破骨細胞・脂肪細胞・血管内皮・骨髄の各血球（好中球、単球、B 細胞、T 細胞、赤芽球、巨核球）の目印になる遺伝子の量をサンプルごとに比べ、
「骨全体の環境」がどう変わったかを読みました。

**何が出たか.** DEG は上昇 518 / 低下 596 個（v1 と同じ）。

- 骨芽細胞の遺伝子が大きく低下（オステオカルシン *Bglap* −3.2 = 約 1/9、*Col1a1* −2.3、*Alpl* −1.7）、骨細胞の遺伝子も低下（*Dmp1* −0.88、*Phex* −1.22、*Mepe* −0.95）。
- 骨髄では好中球（*Ngp*, *Ltf*, *Lcn2*, *Chil3*, *Mpo* が 2–5 倍）と単球が増え、B 細胞（*Cd79a* −1.69、*Vpreb3* −2.27、*Rag1* −2.76）が減少。破骨細胞・脂肪細胞・巨核球の目印もわずかに上昇。
- v1 で「炎症・破骨因子の上昇」とした *S100a9*, *Mmp9*, *Tnf* は好中球の量と、OPG の低下は骨芽細胞の量と、サンプル間でほぼ完全に連動していました。
- ステロイドの印（GR 標的）は *Fkbp5* +0.93 など一部だけ上がり、*Sgk1* は逆に低下。採取時点ではステロイドの直接の反応は部分的です。

**限界.** 雄。DEX 群で骨に無いはずの遺伝子（嗅覚受容体など）の背景リードが多い技術的な偏りがある（補正版でも結論は同じ）。DEX 群は付着した筋肉の量が少ない（筋スコア −2.0）。
bulk なので「骨芽細胞が減った」のか「1 細胞あたりの発現が下がった」のかは区別できません。変化のパターンが加齢マウスの骨とほぼ同じ形になります（後述）。

**評価: ○（Supplementary、または 4C の生体側の補助）**

### GSE276529 — ステロイド性骨粗鬆症（GIOP）患者の皮質骨（案2 のヒト版、v2 資料と同じ）

ヒト女性 51–65 歳、大腿骨皮質骨、GIOP 5 例 vs 非 GIOP 4 例。**OPG 低下（−1.00）がマウスと一致**。GR 標的は上がっておらず（*FKBP5* −0.08）、採取時点でステロイドの作用は見えない。

## 2. 方法

- **counts の復元**（`prelim/fig4c_v4/prepare.py`）: 上記。Ensembl → シンボルは既存の `data/seq/annot/ensembl2symbol.csv`。引けない 144 ID は ID のまま（`prelim/prepare.py` と同じ扱い）。
- **DE**（`de.py`）: 既存 `prelim/de.py` の `run()` をそのまま呼ぶ（pydeseq2、`~ cond`、MLE、edgeR filterByExpr 相当の低発現フィルタ）。検定 13,868 遺伝子。
- **volcano**（`volcano.py`）: 既存 `prelim/volcano.py` の `plot()`。案2 は既存の `out/prelim/de/C_DEX.csv` を描いただけ。
- **GSEA**（`gsea.py`）: 案1 は `prelim/chemo2/genesets.py` の collection（Hallmark 50 + CURATED 17 + 手製 5、MSigDB 2025.1.Mm）で prerank（Wald 統計量、1000 perm、seed 0、min 4、max 1000 = chemo2 と同じ）。
  案2 は既存 `out/prelim/chemo2/nes_wide.csv` の値をそのまま使った。ヒト GIOP（素・骨髄補正・背景補正）は要約図のヒト列と同じく `prelim/invitro/gsea_iv.py` の collection で回し直した。
- **感度分析**: GR 標的 20 遺伝子（事前定義、`compare.py` の `GR_TARGETS`）を順位から抜いて同じ GSEA を回した（`gsea_noGR.csv`）。
- **骨環境の区画スコア**（`compare.py`）: 区画ごとに事前に決めた目印遺伝子（3–8 個、`COMPART`）の log2(CPM+1) の平均をサンプルごとに出し、DEX − 対照を Welch t 検定、14 区画で BH 補正。
  v1 の炎症パネル遺伝子（*S100a8/9*, *Mmp9*, *Tnf*, *Il1b*）は区画の目印に入れていない（循環を避けるため）。
- **一致の評価**: 遺伝子単位は共通遺伝子の Wald 統計量の Spearman と、共通 DEG（strict: padj < 0.05 & |log2FC| ≥ 1、lenient: padj < 0.1 & |log2FC| ≥ 0.585）の同方向・逆方向（超幾何 P）。
  ヒトとは大文字化したシンボルで照合。モジュール単位は同じ 68–71 set の NES の Spearman と、両方 FDR < 0.05 の set 数。set は遺伝子を共有するので独立ではなく、記述用。

## 8. 4C が担うべきもの（意見）

- 依頼資料の 4C には題が無いが、案1・案2 とも中身はステロイドなので、データから見ると 4C は **「化療に併用されるステロイド」** の枠になる。
  乳がんの周術期化療（AC/EC、タキサン）では制吐・前投薬としてデキサメタゾンがほぼ全例で毎サイクル入るので、臨床の「化療」という曝露は **殺細胞薬（4B）＋ステロイド（4C）** の組み合わせ、と位置づけられる。
  これなら 4C が閉経の前後を問わず動くこと自体は問題にならない（4C は「治療側」の成分で、閉経・加齢の背景は 4A が担う）。
- 4C で言うべきことは、3 つのステロイドデータで一貫している **「骨形成の抑制と OPG の低下（RANKL/OPG 比の上昇）」** に絞る。OPG/RANKL はデノスマブの標的そのものなので、
  4A 案1 のデノスマブ群（閉経後の骨代謝回転の抑制）や Discussion の「化療前のデノスマブ」（D-CARE 陰性の反証は併記）と話がつながる。
  4B の Dox とは「骨形成・基質の低下」で同じ向き、「OPG の低下」はステロイドに固有、と書き分けられる。
- **v1 の「ステロイドで炎症とアポトーシス」は書かない。** 案1 では炎症は下がり、アポトーシスは割れる。案2 の炎症遺伝子は好中球・単球の量の変化。
- 推奨構成: **4C 本編 = 案1 の volcano**（GR 標的・骨形成遺伝子・OPG/RANKL をラベル）。可能なら小さな挿入図で OPG の log2FC を 3 データ（案1・案2・ヒト GIOP）並べる。
  **案2 は Supplementary に「骨環境の区画スコア」（`dex_environment.png`）＋ volcano として置き**、生体でも骨芽細胞の減少と OPG 低下が起きること、炎症遺伝子の上昇は骨髄の細胞構成の変化であることを書く。
  案2 が加齢骨とほぼ同じ形になることは隠さず、「ステロイドは骨環境を加齢骨に似た状態（骨芽細胞が少なく骨髄球系が多い）に寄せる」と記述にとどめる（2-hit の根拠には使わない）。
- 清水先生が 4C を「化療後の骨芽細胞」のつもりで案1 を選んでいた場合は、4C はステロイドではなく、4B の Blood 論文（GSE296761）の骨芽細胞 bulk で組むことになる。その判断を先に確認したい。

## 9. 言えること / 言えないこと

言えること:
- 骨芽細胞（MC3T3-E1）に GC を当てると、GR 標的が上がり、骨形成遺伝子（*Runx2*, *Sp7*, *Bglap*, *Ibsp*）と OPG が下がる（in vitro、24 時間）。
- OPG の低下は、培養骨芽細胞・DEX マウス脛骨・ヒト GIOP 皮質骨の 3 つで同じ向き（−1.08 / −1.05 / −1.00）。
- DEX マウス脛骨では、骨芽細胞・骨細胞・B 細胞の目印が下がり、好中球・単球・破骨・脂肪の目印が上がる。v1 の炎症遺伝子の上昇はこの細胞構成の変化と連動する。
- DEX マウス脛骨の変化はマウス加齢骨とほぼ同じ形で、ヒトの閉経後・高齢の生検とは逆向き。

言えないこと:
- 「ステロイドで骨に炎症が起きる」（案1 で炎症は下がる。案2 は細胞構成の変化）。
- 「ステロイドで骨芽細胞・骨細胞がアポトーシスする」（案1 は促進と抑制が混在、案2 は Hallmark apoptosis が ↓。RNA ではアポトーシスそのものは測れない）。
- 「ステロイドで RANKL が上がる」（案1 の上昇は低発現の遺伝子で、生体の案2・ヒトでは上がらない。言えるのは OPG ↓ 側だけ）。
- 「GC と Dox が同じことを起こす」（共通は骨形成・基質の低下だけ。全体の相関は弱い）。
- 閉経・加齢とステロイドの交互作用（データが無い）。臨床でのステロイド累積量の寄与（臨床データに無い、`docs/literature.md` R7）。

## 10. Limitation

- 案1 は細胞株の in vitro・24 時間・1 濃度。コルチコステロン（内因性 GC、MR にも結合）は臨床のデキサメタゾン（GR 選択的・長時間作用の合成 GC）と同一ではない。カルシトリオールが両群に入っている（GEO 記載）。
  n = 3 は培養反復。MC3T3-E1 は未熟な骨芽細胞のモデルで、骨細胞（*Sost* 発現なし、*Dmp1* 30 CPM）ではない。
- 案1 の補足ファイルは名前と中身が違い、正規化 counts から生 counts を復元した（復元誤差 < 0.001）。論文本文の記述（*Rankl* 低下）と寄託データの再計算（*Rankl* 上昇）が食い違う。
- 案2 は雄、骨髄込みの bulk で、細胞数の変化と 1 細胞あたりの発現の変化を区別できない。区画スコアは目印遺伝子 3–8 個の平均で、デコンボリューションではない。
  DEX 群の背景リード artefact、付着筋の量の群差がある。採取時点での GR 標的の応答は部分的。
- ヒト GIOP は n = 5 vs 4 で骨髄混入と群がほぼ交絡し、補正の仕方で結果が変わる。GR 標的が上がっておらず、採取時点のステロイド曝露は不明。
- 4A・4B との比較は、種・性・組織・時間の違うデータの向きの並置で、交互作用の検定ではない。set は遺伝子を共有するので、一致数は独立な証拠ではない。
