# Fig4 予備解析（ヒト）: 骨生検 RNA-seq で閉経・加齢・GIOP を見る（2026-10-12）

マウス予備解析（`docs/prelim_de.md`）で「加齢（雄）だけが炎症＋アポトーシス、OVX・Dox はほぼ空」だったのを、ヒト骨で補えるかを見た。
基準はマウスと同じ（pydeseq2 0.5.4・MLE・edgeR filterByExpr 相当の低発現フィルタ・DEG = |log2FC| ≥ 1 かつ padj < 0.05・パネルは `prelim/genes.py` を大文字化）。
再生成は `bash prelim/human/run_all.sh`。閾値は動かしていない。

## 結論（先に）

- **閉経後 vs 閉経前（GSE141595）は「炎症・アポトーシス・老化」方向にはっきり振れる**: DEG 265（↑237/↓28）。パネルでは **CDKN1A +1.00（padj 4e-07）、IL6 +0.72（0.002）**。
  Hallmark GSEA で TNF-α/NF-κB（NES 2.35）、Apoptosis（2.31）、p53（2.14）、Inflammatory Response（1.81）、IL-6/JAK/STAT3（1.62）、**SenMayo（1.72, FDR 0.003）** がすべて上昇。
  **ただし閉経前 15 例は別バッチ（2022 年追加・別処理・ライブラリ深度 4,200 万 vs 7,300 万）で、群とバッチが完全に交絡**。さらに閉経前ファイルは途中で切れており（後述）、遺伝子の 4 割（chr12 後半〜22, Y, M）が比較できない。単独では根拠にならない。
- **高齢 vs 若年（GSE72815、同一バッチ・独立コホート）が同じ方向を再現する**: DEG 89（↑82/↓7）。パネルでは **CDKN1A +0.47（padj 0.0006）、TNF +0.35（0.007）、CCL2 +0.80（0.002）**。
  GSEA で SenMayo ↑（NES 1.65, FDR 0.007）、p53 ↑（1.41, FDR 0.05）。ただし Inflammatory Response / TNF-α はむしろ弱く負（NES −1.23 / −1.10, 有意でない）。
  **GSE141595 閉経後/閉経前と GSE72815 高齢/若年の log2FC は Spearman ρ = 0.56**（lenient 共通 DEG 同方向 149 / 逆方向 5）。バッチ交絡のある GSE141595 の変化の相当部分は、バッチのない GSE72815 でも出る＝生物学的な成分を含む。
  共通の上昇は血管内皮・平滑筋・ECM 系（NOS3, SOX17, SPARCL1, ELN, LAMA2, FLNC …）が中心で、組成（血管・間質の割合）の差も疑う。
- **マウス加齢（雄、皮質骨）とヒト高齢/閉経後は全体として逆相関**（Spearman ρ: Age_2.5y vs H_Old −0.30、vs H_PostMeno −0.33。Myogenesis/EMT 遺伝子を除いても −0.28 / −0.32）。
  共通 DEG も逆方向が多い（lenient: H_Old で同方向 26 / 逆 113）。同方向に揃うのは免疫・炎症系の一部（TREM2, CCL2, CCL8, GDF15, FGF23, HSD11B1, LAG3, CD274, 肥満細胞 CPA3/MS4A2）。
  パネルで両種とも有意に上がるのは **TNF と CCL2（ヒト高齢）だけ**。マウス加齢で出た IL1B・S100A8/9・FASLG・PMAIP1・BBC3・BCL2 はヒトでは動かない。**CDKN1A は向きが逆**（マウス −0.60、ヒト +0.47 / +1.00）。
- **マウス OVX（A_OVX_cort）とヒトは関係が見えない**（ρ = 0.10〜0.12、共通 DEG 0〜1）。マウス側の DEG が 5 個しかないため。
- **ヒト GIOP（GSE276529）はマウス DEX（GSE276391、同じ論文）と有意に一致する**: ρ = 0.27（bg 補正同士 0.29）、lenient 共通 DEG 同方向 298 / 逆 73（up・down とも超幾何 P < 1e-3）。
  両種で揃って下がるのは **OPG（TNFRSF11B: ヒト −1.00, padj 0.003 / マウス −1.05）、OSTN（−4.25 / −2.52）、IGF1（−1.06 / −0.99）**、ECM・軟骨系（COL2A1, ACAN, COL11A2, DKK3, SFRP2）。
  ただし揃って上がる側は CHRNA4, OTX1, PAX2, SIX3, LHX1 など骨で発現しない遺伝子が多く、**両データに共通の背景リード（gDNA 様）artefact** の疑いが強い（ヒトも嗅覚受容体 CPM が他データの 30 倍）。
  パネルではアポトーシス系が少し出る（BAX +0.47 padj 0.051、CDKN2A +0.62 padj 0.035、MDM2 −0.39 padj 0.038）が、炎症系（TNF, IL1B, S100A8/9, MMP9）は**有意にならない**（マウス DEX で出た炎症↑はヒトでは再現しない）。
  **GIOP 群は骨髄・血液の混入が多い**（HBB 中央値 3,319 vs 385 CPM、MPO 421 vs 46）。混入スコアを共変量に入れると OPG 低下は −0.58（padj 0.22）に弱まり、Hallmark は炎症・SenMayo が上向きに反転する（TNF-α NES +2.08）。n = 4 vs 5 で混入と群がほぼ交絡しており、GIOP のパスウェイ結果は補正の仕方で向きが変わる＝不安定。
- **デノスマブ（閉経後 placebo との比較）は破骨・骨形成マーカーの低下だけ**: DEG 28（すべて↓）。SIGLEC15, ACP5, CTSK, ATP6V0D2, MMP9（−0.70）, MMP13（−2.01）と COL1A1/COL1A2/SPARC/IFITM5（骨形成）が下がる＝骨代謝回転の抑制（薬効の陽性対照としては妥当）。
  GSEA では TNF-α/NF-κB（NES −1.82, FDR 0.001）・Inflammatory Response（−1.58, 0.017）が下がる。**閉経後で上がった CDKN1A・IL6 はデノスマブで戻らない**（−0.15, −0.18, 有意でない）。SenMayo も有意でない（−1.03）。
  遠心のみ（消化なし）の GSE141610 でも同じ破骨・骨芽系の低下が出る（H_Dmab と lenient 共通 30、すべて同方向、ρ(有意遺伝子) = 0.64）。
- **高齢+E（3 週）vs 高齢** は DEG 9 でほぼ空。パネルも全滅（マウス ERT の大きな変化とは対応しない、ρ = 0.08）。

## 処理

- `prelim/human/prepare.py`: 同一シンボル合算、RSEM 非整数は四捨五入。GSE72815 の counts は全値偶数（mate 二重計数）なので /2（GSE222752 と同じ）。
  GSE276529 の Ensembl → シンボルは GSE141595 の GeneID/GeneName 列で引いた（`data/seq/GSE141595/human_ensembl2symbol.csv`）。発現ありで引けなかった ID 1,236 は ID のまま（パネル・組成マーカーはすべて引けている）。
- DE は `prelim/de.py` の `run()` をそのまま呼ぶ（`prelim/human/de_h.py`）。volcano・閾値集計は `prelim/volcano.py` の `plot()` / `THRESHOLDS`、enrichment は `prelim/enrich.py` の `ora()` / `gsea()` を、ライブラリだけヒト版（GO_BP_2023, KEGG_2021_Human, MSigDB_Hallmark_2020）に差し替えて使用。
- **SenMayo** は MSigDB C2 `SAUL_SEN_MAYO`（2023.2.Hs, 125 遺伝子）を Hallmark ライブラリに 51 番目のセットとして足し、ORA と prerank GSEA の両方で評価（FDR は 51 セットで計算）。
- マウスとの突き合わせ（`prelim/human/compare_h.py`）: マウスシンボルを大文字化してヒトと照合（パネル内の Fasl→FASLG, Trp53→TP53 は手当て）。大文字化後に重複する遺伝子は除外。
  1:1 にならない遺伝子（H2-*/HLA-*、Hbb-bs/Hba-a1、Ly6*、Olfr/OR、Gm*、Klk・Cyp・Serpina・Ces 等の種特異的拡大ファミリー、Ifi20x 等）は一致しないか誤対応しうる。共通に検定された遺伝子は 7,100〜12,800（マウス側の 48〜82%）。
  閾値 3 段階（strict / lenient: padj<0.1 & |lfc|≥0.585 / nominal: p<0.01 & |lfc|≥0.585）で共通 DEG と超幾何 P、log2FC の Spearman を出した。

1. **GSE141595 は "osteocyte enriched" と書かれているが、実際は骨髄・血液が主成分**（HBB だけで全リードの 6% 前後、MPO・ELANE 高値）。骨細胞マーカー（SOST, DMP1）は皮質骨（GSE276529）の 1/30〜1/60で、消化しない GSE141610 より低い。「骨細胞のトランスクリプトーム」とは呼べない。GSE72815 も同様（骨髄込みの生検）。
2. **GSE141595 閉経前ファイルの欠落**: 閉経前ファイル（`GSE141595_Raw_Data_GSM6246351-GSM6246365_June_13_2022.csv.gz`）は 37,163 行で、chr1〜11, X と chr12 の先頭 180 遺伝子で**途中で切れている**（閉経後ファイルと同じ並び順で、chr12 の途中以降・chr13〜22・Y・M・alt contig の 27,090 ID が無い）。単なる遺伝子フィルタではない（欠けた側に COL1A1, MPO, HBA2, MT-* など高発現遺伝子が多数）。
   - 影響 1: パネルのうち TNFSF11, CCL2, MMP9, SOST, BAX, BCL2, BCL2L1, TP53, MDM2, PMAIP1, BBC3 は **H_PostMeno で検定不能**（表の —）。組成マーカーも COL1A1, MPO, CKM, SOST などが使えない。
   - 影響 2: サイズ因子は共通遺伝子だけで推定。閉経後同士の比較で全遺伝子版（H_Dmab）と共通遺伝子版（H_Dmab_common）を比べると DEG 28 vs 23、パネル log2FC の差は ±0.01 程度で、**遺伝子集合を絞ったこと自体の影響は小さい**。
   - 影響 3（本質的）: 閉経前は別時期・別処理で、群＝バッチ。閉経後で下がった遺伝子の上位が HSPA1A/HSPA1B/HSPA6/DNAJB1 などの熱ショック応答（GO "Cellular Heat Acclimation" padj 8e-07）で、検体処理（温度・時間）の差を示唆する。バッチ補正は不可能。
   - 完全にそろえるには SRA（SRP234994）からの再アライメントが必要（今回は見送り）。
3. **GSE276529**: GIOP 群は骨髄・血液混入が多い（4/5 例が HBB > 600 CPM、非 GIOP は Ctrl_4 以外 < 430）。GIOP_5 は COL1A1/CTSK/BGLAP が他の 1/10 で外れ（PCA でも外れ）。
   嗅覚受容体 CPM ~1,000（他データ ~35）で背景リードが多いが、マウス GSE276391 と違い**群間の偏りはない**（GIOP 中央値 1,012 vs 1,165）。
   **GC 応答遺伝子（FKBP5, TSC22D3, PER1, ZBTB16）は GIOP で上がっていない**（マウス DEX では Fkbp5 +0.93）。採取時点で GC 曝露が続いていないか、慢性曝露で応答が減衰している。「GC 作用」より「GIOP の骨の状態」を見ていると解釈すべき。
4. **GSE72815**: PCA の PC1（66%）は骨格筋混入（ACTA1/CKM/MYH7）の多い数例で決まる（s_3, s_42 など、Old_E に多い）。H_Old の上昇 DEG に CKM, MYOM3, NEB が入り、Hallmark Myogenesis が最上位（NES 2.97）なのはこの混入の寄与が大きい。
5. 性別は全例女性（XIST 高・RPS4Y1/DDX3Y ほぼ 0）。

## Fig4A / 4C への採用可否（推奨）

1. **Fig4A（閉経）: GSE72815（H_Old）を主、GSE141595（H_PostMeno）を補助として採用を推奨。**
   - ヒト女性・同一バッチで、CDKN1A・TNF・CCL2 の上昇と SenMayo 上昇が出る。GSE141595 の閉経後/閉経前は効果が大きく SenMayo・Apoptosis・TNF-α・IL-6 がそろって上がるが、バッチ完全交絡と遺伝子欠落があるので単独では使えない。両者の ρ = 0.56 を「独立コホートで再現」として添えるのが安全。
   - ただし H_Old は「加齢＋閉経」の混合（30 vs 73 歳）で、閉経単独の効果ではない。H_PostMeno も 25–37 vs 60–79 歳で同じ。**「閉経」ではなく「閉経後の加齢骨」と書くべき**。
   - 炎症系パスウェイ（Inflammatory Response, TNF-α）は H_Old では上がらない。強く言えるのは「老化（p21/SenMayo）」で、「炎症」は TNF/CCL2 の遺伝子レベルにとどまる。カスパーゼ等のアポトーシス実行因子は出ていない。
   - 組織は骨髄主体の腸骨生検で、骨細胞のデータではない（SOST/DMP1 は皮質骨の 1/30 以下）。
   - マウス加齢（Age_2.5y）とは遺伝子全体で逆相関。「マウスとヒトで同じシグネチャ」とは書けない。マウス加齢とヒトで共通するのは TNF・CCL2 と GSEA の p53/老化方向程度。
   - GSE141595 を本番で使うなら SRA（SRP234994）から 45 例をそろえて再アライメントする価値はある（欠落遺伝子の回復。バッチ交絡は残る）。
2. **Fig4C（ステロイド）: GSE276529 はマウス 4C（GSE276391）の補助パネルとして「OPG 低下の種間一致」に絞るなら採用可。**
   - 遺伝子全体で有意に一致し（ρ 0.27、共通 DEG 同方向 298 vs 逆 73）、OPG・IGF1・OSTN の低下がそろう。
   - ただし n = 4 vs 5、骨髄混入が群とほぼ交絡（補正で OPG 低下は −0.58, padj 0.22 に弱まる）、背景リードが多い、GC 応答遺伝子が上がっていない（採取時に GC 作用が見えない）。炎症系はヒトで再現しない。アポトーシス系（BAX, CDKN2A）は境界的で補正に敏感。**パスウェイ結果は補正で向きが変わるので図には使わない方がよい**。
3. **デノスマブ（H_Dmab）は Fig5 の考察用**: 破骨・骨形成マーカーは下がるが、閉経後で上がった CDKN1A・IL6・SenMayo は戻らない（RANKL を止めても老化シグネチャは残る、という読みは可能。ただし効果量は小さく n=15 で非有意＝「戻らない」の証明ではない）。
4. **高齢+E（H_OldE）は使わない**（3 週投与で DEG 9、パネル全滅）。
