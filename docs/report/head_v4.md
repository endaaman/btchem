# 要点

この資料は、10/14 にいただいた解析依頼資料（「Osteocyte から骨全体の環境を対象に広げ Figure 4A/B/C を作成する方針」）を背骨にして、
10/12 資料（v1）と 10/16 資料（v2）の中身を**一つも落とさずに**並べ替えたものです。ご依頼の新しい解析（v4）は進行中で、
結果が出た箇所から埋めていきます（解析中の箇所には「v4 の解析待ち」と書きました）。

- **第 1 章 Figure 4A（加齢性変化）**
  - 案 1（GSE141595、ヒト閉経後 vs 閉経前）: Inflammatory response（NES +1.81）と Apoptosis（+2.31）の上昇は v2 で出ています。
    ただし閉経前群が別バッチで、群とバッチが完全に重なっています。デノスマブ vs placebo は v2 で一次解析済み
    （DEG 28 個ですべて低下。閉経後で上がった p21・IL6・SenMayo はデノスマブで戻らない）。v4 で深掘り中です。
  - 案 2（GSE235942、雌の皮質骨 22 か月 vs 6 か月）と案 3（GSE255653、骨髄 MSC の老齢 vs 若齢）: v4 で新規に解析中です。
  - 案 4（現行 4A、Kaya 2022、雄）: 炎症は上がるが RANKL は低下し、アポトーシスの遺伝子セットは上がらない（v1・v2）。v4 で解釈を再検討中です。
- **第 2 章 Figure 4B（ドキソルビシン、Blood 2026 = GSE296761）**: bulk の LepR+ 骨髄間質（GSE296758）と骨芽細胞（GSE296757）は
  GSE296761 の一部で、v2 で解析済みです（LepR+ 間質で骨形成・基質・血管とエストロゲン標的が低下し、アポトーシス・老化・炎症は動かない。
  骨芽細胞は DEG 11 個）。論文の要約と単一細胞（GSE296752）の解析は v4 で新規です。GSE296761 には、v2 で不採用にしたヒト ALL の骨髄間質
  （GSE318370）も含まれていました。GSE289491（*Nat Commun* 2025）は GSE296761 とは別の研究室のデータなので、関連データに置きました。
- **第 3 章 Figure 4C**: 案 1（GSE304562、マウス骨芽細胞の bulk）は v4 で新規です。案 2（現行 4C、DEX、GSE276391）は v1 で解析済み
  （炎症因子の上昇と OPG の低下）で、v4 で活かし方を検討中です。
- **第 4 章以降**: 臨床（Fig. 1–3、変更なし）、v2 の解析の横断のまとめ（要約モジュール図など）、図と仮説の構成オプション、文献、
  探して無かったもの、不採用データ、解析の方法、v1・v2 の要点を、背骨の後ろに置きました。
- 確認したい事項は各案の節の末尾に置き、資料の末尾にまとめも付けました。
