# 案 2: 現行 Figure 4C の活用（GSE276391、DEX）

## 依頼（原文）

> 案2 ：現行のFigure4C の活用\
> GSE２７６３９１

## データセットの説明

### GSE276391 と GSE276529 — ステロイド（DEX / GIOP）（v1 の Figure 4C / S1E）

同じ論文（PMID 39641269）のマウス版とヒト版です。

**GSE276391**: マウス**雄** 3 か月、デキサメタゾン 1 mg/kg 皮下 5 日 vs 対照、各 5 匹。脛骨（凍結粉砕、骨髄込み）。同じ実験に脛骨への荷重刺激の群もありますが使っていません。

**GSE276529**: ヒト**女性** 51–65 歳、大腿骨の皮質骨、ステロイド性骨粗鬆症（GIOP）5 例 vs 非 GIOP 4 例。

### v2: GSE276391 と GSE276529（データセットの章より）

**GSE276391**（結果）: DEG は上昇 518 / 低下 596 個。*Tnf* +1.23、*Il1b* +0.80、*S100a9* +1.27、*Mmp9* +0.97 が上昇、**OPG（*Tnfrsf11b*）-1.05 が低下**（RANKL/OPG 比の上昇）。アポトーシス系は有意なし。
DEX 群で骨では発現しない遺伝子（嗅覚受容体など）の背景リードが多い技術的な偏りがあり、上昇 DEG の約 1/3 がこの系統でした（補正しても注目遺伝子の結論は不変）。

**GSE276529**（結果）: DEG は上昇 618 / 低下 298 個。**OPG の低下（-1.00）がマウスと一致**しました。
ただし GIOP 群に骨髄・血液の混入が多く、補正すると OPG 低下は -0.58（有意でない）に弱まります。ステロイドに反応する遺伝子（*FKBP5* など）が上がっておらず、採取時点でステロイドの作用は見えていません。

### v1: Supplementary Figure S1E（ヒト GIOP）

- **E（ヒト GIOP）**: マウス DEX と同じ論文のヒト版です。**OPG の低下がマウスとヒトで一致**しました。炎症系はヒトでは有意になりませんでした。

## 言えること・言えないこと

**評価: ○（Supplementary）** 打合せで「閉経前後を問わず動くので話を混乱させる」として本編から外す方向になりました。解析でも、DEX の変化のパターンは加齢とほぼ同じ形（NES の Spearman 0.87）で、「加齢の炎症はどんな侵襲でも出る非特異的な反応では」という反論の材料にもなります。

v1 の「図に関する注意点」の 3:

3. 4C（GSE276391）は DEX 群で背景のリード（嗅覚受容体など、骨で発現しない遺伝子）が多いという技術的な偏りがあり、上昇遺伝子の約 1/3 がこの系統です。背景を補正した解析でも注目遺伝子の結論（*Tnf*, *Il1b*, *S100a9*, *Mmp9* 上昇、OPG 低下）は変わりませんでした。
