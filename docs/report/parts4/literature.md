# この章について

本研究の仮説（閉経後の骨 = 1st hit ＋ 周術期化療・ステロイド = 2nd hit → 骨の pre-metastatic niche → 骨転移）について、
支持する文献・反する文献・先行研究の有無をまとめました。PMID はすべて PubMed（NCBI E-utilities）で実際に書誌と抄録を取得して確認したものです。
確認できなかったものは末尾に分けました。詳しい一覧（Introduction / Discussion の段落構成案、査読対応案を含む）は `docs/literature.md` にあります。

# 1. 先行研究の有無

- **「骨転移の 2-hit モデル」をはっきり名乗った文献は見つかりませんでした**（検索語: two-hit model bone metastasis niche priming、sequential insults など）。
- 最も近い先行例は次の 3 本で、いずれも「hit は 1 つ」の枠組みです。

| 文献 | 内容 | 本研究との関係 |
|---|---|---|
| Luo 2016 *Cell Rep*（PMID 26725121） | 老化した骨芽細胞を誘導するだけで、乳がんの骨コロニー形成が増える（SASP → 局所の破骨細胞誘導） | 2nd hit（宿主側の変化）だけを切り出した形 |
| Ottewell 2014 *Clin Cancer Res*（PMID 24687923）/ 2015 *Int J Cancer*（PMID 25603921） | OVX だけで、骨の休眠 DTC が破骨細胞依存に増殖する。骨外の腫瘍には影響なし | 1st hit（閉経）だけを切り出した形 |
| Cheng 2022 *Int J Mol Sci*（PMID 35163300） | エストロゲン欠乏とステロイド過剰の骨代謝への影響を並べて整理した総説（転移には触れない） | 2 つの hit を同じ枠で語る下敷き |

→ **「閉経（1st）× 化療＋ステロイド（2nd）の重ね合わせ」として定式化した例は無く、ここが本研究の新規性**になります。

- また、「**化療が骨転移を増やす**」ことを示した前臨床モデルも見つかりませんでした（肺・肝では報告あり、下記 3 節）。乳がん骨転移モデル × 化療、× 閉経の RNA-seq データも存在しません。これは新規性であると同時に Limitation でもあります。
- 用語の注意: "two-hit" は Knudson のがん抑制遺伝子仮説を連想させるため、**"sequential two-insult model" / "priming-and-trigger model"** と言い換えることをお勧めします。

# 2. 仮説を支持する文献

## 2-1. 閉経後の骨でのみ DTC が目覚め、抗吸収薬が効く（最も強い）

| 文献 | 要点 |
|---|---|
| Ottewell 2014 *Clin Cancer Res*（PMID 24687923） | OVX で骨内の腫瘍形成 83% vs sham 17%。骨外は変化なし。ゾレドロン酸は OVX 群でのみ腫瘍形成を阻止 |
| Ottewell 2015 *Int J Cancer*（PMID 25603921） | OVX で休眠 DTC が増殖、OPG-Fc（RANKL 阻害）で抑制 |
| EBCTCG 2015 *Lancet*（PMID 26211824） | 術後 BP のメタ解析（18,766 例）。**閉経後でのみ**骨再発 RR 0.72、乳がん死 0.82。閉経前では効果なし |
| AZURE 最終（Coleman 2014 *Lancet Oncol*、PMID 25035292） | 閉経後 5 年超の群でのみ IDFS HR 0.77 |

→ 本研究の「閉経後でのみ化療と骨転移が関連する」所見と鏡像の関係にあります。

## 2-2. 骨に特異的であること

- OVX は骨内の腫瘍だけを増やし、骨外には影響しない（PMID 24687923）。本研究の「骨転移のみ関連、肺・肝は関連なし」と一致し、**臓器特異性は仮説の最大の強み**です（適応バイアスへの反論にもなる: 化療を受けた人が元々高リスクなだけなら、肺・肝の転移も増えるはず）。

## 2-3. 化療・ステロイドは骨の細胞を直接傷める

| 文献 | 要点 |
|---|---|
| Yao 2020 *Cancer Res*（PMID 31932453） | 化療後の骨減少はエストロゲン非依存の老化細胞・SASP による |
| Wasi 2024 *Bone*（PMID 39147353） | Dox が成熟マウスで骨細胞アポトーシスを増やす（組織学） |
| Izquierdo 2026 *GeroScience*（PMID 42686970） | Dox の骨への影響は雌・高齢でより強い |
| Weinstein 1998 *J Clin Invest*（PMID 9664068） | ステロイドが骨芽細胞・骨細胞のアポトーシスを起こす（GIOP の中心機序） |
| Weinstein 2011 *Endocrinology*（PMID 21771887） | OPG（RANKL 阻害）がステロイドによる骨細胞アポトーシスを防ぐ |
| Shapiro 2001 *J Clin Oncol*（PMID 11454877） | 化療で卵巣機能不全になった女性で急速な骨量減少 |

## 2-4. 2 つの hit が骨細胞 → RANKL → 破骨細胞に収束する

- 骨細胞は骨の主要な RANKL 供給源（Nakashima 2011 *Nat Med*、PMID 21909105; Xiong 2011 *Nat Med*、PMID 21909103）。
- アポトーシスした骨細胞の周囲の生存骨細胞が RANKL を出す（Kennedy 2012 *Bone*、PMID 22342796）。
- エストロゲン離脱でも骨細胞アポトーシスが起きる（Tomkinson 1997、PMID 9284757; Emerton 2010、PMID 19925896）。
- 破骨細胞による骨リモデリングが休眠細胞を再活性化する（Lawson 2015 *Nat Commun*、PMID 26632274）。
- 閉経直後の女性で骨髄の RANKL が上昇（Eghbali-Fatourechi 2003、PMID 12697741）。エストロゲン欠乏は TNF 産生 T 細胞を介して骨を減らす（Cenci 2000、PMID 11086024; Roggia 2001、PMID 11717453）。

## 2-5. 化療は宿主側を変え、薬が抜けた後も転移を促す（ただし肺・肝）

| 文献 | 要点 |
|---|---|
| Karagiannis 2017 *Sci Transl Med*（PMID 28679654） | 術前化療後の残存腫瘍で転移の入口（TMEM）が増える |
| Keklikoglou 2019 *Nat Cell Biol*（PMID 30598531） | タキサン・アントラサイクリンが腫瘍由来 EV を介して肺の pre-metastatic niche を作る |
| Daenen 2011 *Cancer Res*（PMID 21975929） | 化療で前処理した宿主（薬は消失済み）で転移が増える |
| He 2025 *Cancer Cell*（PMID 40614736） | Dox・シスプラチンが休眠乳がん DTC を目覚めさせ肺転移を増やす（NET 経由） |
| Demaria 2017 *Cancer Discov*（PMID 27979832） | 化療誘発の老化細胞が再発・転移を促す |
| Volk-Draper 2014 *Cancer Res*（PMID 25274031） | パクリタキセルが骨髄を含む全身で炎症を起こし転移を増やす |

→ 「化療が転移の土壌を作る」こと自体は確立していますが、**骨については誰も調べていない**ことが本研究の位置づけになります。

## 2-6. 時間のスケール

- ER+ 乳がんは内分泌療法終了後も 20 年にわたり再発し続け、骨が主な部位（Pan 2017 *NEJM*、PMID 29117498）。
- 診断時にすでに骨髄に DTC が存在し、予後因子になる（Braun 2005 *NEJM*、PMID 16120859）。
- → 周術期の数か月の変化が、数年後の骨転移として現れるという筋は通ります。

# 3. 仮説に反する文献・弱点

| 文献・論点 | 内容 | 本文での扱い（案） |
|---|---|---|
| **D-CARE**（Coleman 2020 *Lancet Oncol*、PMID 31806543） | 高リスク早期乳がん 4,509 例で、標準治療（化療含む）＋デノスマブは**骨転移無発生生存を改善せず**（HR 0.97） | 最大の反証。ただし閉経前後が混在。骨の健康は改善した（PMID 34185259）ので「骨量を守る ≠ niche を無効化する」。「化療前のデノスマブ」は**推奨ではなく、閉経後 ER+ に絞った試験が必要という仮説**として書く |
| Ali 2025 *Sci Rep*（PMID 40389522） | AC-T 相当の化療で骨量減少は持続するが、senolytic で防げず、後期には老化マーカーも検出されない | 老化（SASP）を 2nd hit の唯一の機序にしない |
| Lin 2026 *J Clin Invest*（PMID 42138086） | ER+ 骨転移の約 40% はデノスマブ下でも進行（RANKL 非依存の破骨細胞活性化） | 「RANKL 阻害が唯一の手」と書くなら、効かない経路があることも書く |
| 骨での直接証拠が無い | 化療が骨転移を増やす前臨床モデルは見つからない | 新規性かつ Limitation |
| 臨床側の交絡 | 化療を受ける患者は元々高リスク。AI の使用、骨スキャンの頻度（検出バイアス） | 多変量調整、臓器特異性、AI での層別を示す |
| ステロイドの量が不明 | 臨床データに制吐ステロイドの累積量が無い（と思われる） | ステロイドは「仮説上の共因子」とトーンを抑える |

# 4. 本研究の公開データ解析との関係

- 文献では「化療・ステロイド → 骨細胞アポトーシス」が組織学的に報告されています（2-3 節）が、**本研究の公開 RNA-seq 解析では、アポトーシス遺伝子の有意な上昇はどのデータでも見られませんでした**（Figure 4 資料）。
- 代わりに見えたのは、ステロイドによる **OPG 低下（RANKL/OPG 比上昇）と炎症因子の上昇**、化療による**骨形成系の低下**、閉経後・加齢の骨での**炎症・老化**です。これらは 2-4 節（RANKL → 破骨細胞への収束）と矛盾しません。
- したがって、アポトーシスは Discussion で既報として触れ、図（Figure 5）の骨格は RANKL/OPG・炎症・骨形成抑制で組む形をご提案しています。
- 補足: 骨転移の pre-metastatic niche で S100A8/A9 を扱った**骨での**先行文献は見つかりませんでした。本研究で S100a8/9 の上昇を論じる場合は、骨での先行文献は無いと書くのが正確です。
