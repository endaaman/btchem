# 用語

- **bulk RNA-seq**: 組織や分取した細胞の集団をまとめて測る方法です。細胞の平均を見るので、どの細胞がどれだけ混ざっているか（**組成**）の影響を強く受けます。
  **組成の補正**は、血液・筋などの目印遺伝子の量をサンプルごとに測り、その差を統計モデルで差し引くことです。目印の量が群で完全に分かれていると補正は外挿になり、当てになりません。
- **単一細胞 RNA-seq と擬似バルク**: 細胞を 1 個ずつ測る方法です。同じ細胞種と判定した細胞の発現を合算したもの（擬似バルク）を作り、bulk と同じように比べます。UMAP は、発現の似た細胞が近くに並ぶように全細胞を平面に描いた図です。
- **DEG と log2FC**: DEG は 2 群で発現が有意に違う遺伝子です（調整済み p〔padj〕< 0.05 かつ 2 倍以上の変化）。log2FC は変化の大きさで、+1 が 2 倍、−1 が半分です。
- **遺伝子セットと NES**: 同じ働きの遺伝子の集まり（炎症反応、骨化、ECM など）が、まとまって上がるか下がるかを見る解析（GSEA）の指標が NES です。+ が上昇、− が低下で、FDR（多数の検定を補正した p）< 0.05 を有意、0.05–0.25 を傾向としました。
  2 つの比較の「形」の近さは、同じ遺伝子セット群の NES の Spearman 相関（+1 で同じ向き、−1 で逆向き）で表しました。
- **SenMayo**: 老化細胞とその分泌因子（SASP）の遺伝子を集めた、老化の遺伝子セットです（Saul et al. 2022）。
- **破骨支持**: 破骨細胞の分化・骨吸収を促す遺伝子群（RANKL など）です。OPG は RANKL を塞いで破骨細胞を抑える因子で、RANKL/OPG 比が上がると破骨に傾きます。
- **LepR+ 間質（CAR 細胞、MSPC）**: 骨髄の中で造血幹細胞を支える間葉系の細胞です。骨芽細胞・脂肪細胞の前駆細胞でもあり、がん細胞が骨に住みつく場（niche）の候補とされています。

# 全体として言えること

- **加齢の骨**: 雄マウスでは、11 か月以降に炎症と破骨支持が上がります（2 つの独立したデータで一致）。Kaya では免疫細胞（T 細胞・形質細胞・マクロファージ）と IFN 応答も増えます。
  雌・閉経のマウスで使えるデータは見つからず、4A は「閉経」ではなく「加齢」として書くのが正確です。
- **加齢と Dox の共通点**: 加齢した LepR+ 間質と、Dox を受けた LepR+ 間質で、骨形成・ECM・血管の遺伝子群が同じ向きに下がります。4A と 4B をつなぐ軸はここです。
- **Dox とステロイドの違い**: Dox は IFN-γ 応答を上げますが、RANKL（破骨支持）は上げません。ステロイドは骨形成と OPG を下げます（RANKL/OPG 比の上昇）。
  両者に共通するのは骨形成・基質の低下だけで、OPG の低下はステロイドに固有です。
- **出なかったもの**: アポトーシスは、遺伝子セットが上がる比較もありますが、どれもバッチ・組成・混入の差と重なるか、促進側と抑制側の遺伝子が両方動いていて、「アポトーシスが上がる」とは書けません。
  ヒトの閉経後の炎症の上昇も、バッチの揃ったデータでは再現しませんでした。

## 4A-①: 雄マウスの皮質骨の時系列（Kaya 2022）

雄 C57BL/6 の上腕骨皮質骨（骨髄を遠心で除去）、2 か月 n = 3、11 か月・23 か月・30 か月 各 n = 4 の bulk RNA-seq です。公開されているのは著者の結果表（2 か月との比較）だけです。

- **試料は「骨細胞」ではなく「筋・骨髄を含む骨の組織」**: 雌の大腿骨皮質骨（GSE222752）と比べて、骨細胞の *Sost* が 1/12、骨芽細胞の *Bglap* が 1/15、骨格筋の *Acta1* が 6 倍・*Ckm* が 10 倍で、顆粒球・形質細胞のマーカーも多い組織です。

## 4A-②: 雄マウスの脛骨 22 vs 6 か月（GSE235942）

Meas 2024（*Bone*）のデータで、骨髄を洗い流した脛骨全体（成長板・海綿骨・付着した筋を含む）です。ご依頼の雌に加えて、同じデータの雄（22 か月 n = 10、6 か月 n = 5、対照群どうし）を解析しました。原著で解析されているのは雄です。

- 炎症反応 +1.59、破骨分化の正の制御 +1.92、骨吸収 +2.28（いずれも FDR < 0.05）が上がります。DEG は上昇 43 / 低下 13 個です。
- 組成（血液・筋の量）を補正しても、炎症反応 +2.01、IFN-α +2.76、SenMayo +1.55 は残ります。p16（*Cdkn2a*）+1.99（padj 0.006）。
- 骨形成 +1.82・ECM +2.10 は上がる向きですが、組成を補正すると −1.07 / −1.13（有意でない）に変わります。骨形成・ECM は組成に左右されるので、この比較では主張に使いません。

**雌（ご依頼の比較、22 か月 n = 3 vs 6 か月 n = 4）を使わない理由.** 22 か月の雌は、骨に残った血液（*Hbb-bs*/*Hba-a1*）が 6 か月の約 1/16、白血球（*Ptprc*）が約 1/2、付着した筋が約 3 倍で、群で完全に分かれています（図 A3 の C）。
素のままでは炎症反応 −2.05、IFN-α −2.52 と下がりますが、組成を補正すると向きが逆になり、補正版も不安定で、どちらの向きも主張できません。雌のサンプルは原著では解析されておらず、GEO にだけあります。
組成に左右されにくい個別の遺伝子では、p16（*Cdkn2a*）+1.33（padj 0.001）と *Eda2r* +2.02 が上がります（表 A4）。

## 4A-③: 雌マウスの LepR+ 骨髄間質 18 vs 3 か月（GSE255653）

Ramalingam 2025（*Sci Immunol*）のデータで、生体の骨髄から FACS で分取した LepR+ 間質（CD45− TER119− CD31− LEPR+）、各群 n = 3 です。性別の記載は無く、発現から全例雌と推定しました。
GEO には FPKM しか無いため、カウントを復元して解析しました（丸め誤差の小さい遺伝子の 99.3–99.9% で、整数との差が 0.1 未満）。

- **骨形成・ECM・血管が下がる**: GO ossification −2.22、NABA core matrisome −2.63（いずれも FDR < 0.05）、血管新生 −1.51（FDR < 0.25）。*Bglap* −4.43、*Sp7* −1.10、*Spp1* −1.65、*Igf1* −1.45、*Adipoq* −1.02（いずれも padj < 0.05）。
- 血球・内皮で高い遺伝子（混入しうる遺伝子）1,904 個を除いても残ります（−2.50 / −2.83 / −1.70、いずれも FDR < 0.05）。
- 老齢マウスの LepR+ / CAR 細胞を分取した別の公開データ 2 本（GSE130885、GSE133922）や、Dox を受けた LepR+ 間質（4B、Dox × 4 / × 1）と同じ向きです（NES の Spearman +0.30 / +0.41 / +0.42 / +0.55）。
- **炎症の上昇は使えません**: 老齢の 3 例すべてに形質細胞の転写物（*Igkc* がリードの 1.8–11%）があり、*Il1b*・*Tnf*・*Il6* の上昇はそのうち 2 例だけです（図 A3 の D）。混入しうる遺伝子を除くと SenMayo は +1.24 から −1.82（FDR < 0.05）に反転し、p21（*Cdkn1a*）は −1.32 と下がります。

# 6. 確認したいこと

1. **4C 案 1（GSE304562）はステロイドのデータです。** 骨芽細胞株にコルチコステロンを 24 時間当てた実験でした。ステロイドのデータと承知のうえで選ばれたでしょうか。
   承知のうえであれば、4C を「化療に併用されるステロイド」の枠とし、案 1 を本編、案 2（DEX 脛骨）を Supp とする構成でよいでしょうか。
   化療後の骨芽細胞を意図されていた場合、該当するのは 4B の論文の骨芽細胞 bulk（GSE296757）ですが、遺伝子単位の変化はほぼありません。
2. **4B の CD8+ TEM が出ている UMAP はどの図でしょうか**（論文の図番号か、資料の名前）。GEO の単一細胞データは T 細胞を除去した標本で、CD8+ TEM は居ません。
3. **4A を Kaya（11 か月を基準にした成体どうしの比較）と GSE235942 の雄で組んでよいでしょうか。** よろしければ、Kaya の生データからの再定量（半日）を進めます。
   この場合、雌の脛骨は使わず、4A は「閉経」ではなく「加齢」として書くことになります。
4. **4A 案 1 のデノスマブ（否定的な結果）は、Discussion と Supp のどちらに回しますか。**
5. **化療の情報が空欄の 43 例**（閉経前 23 / 閉経後 20）の化療の有無を補えるでしょうか。補えない場合、Figure 1 に除外として明示してよいでしょうか。
6. **抄録の HR 2.05（95% CI 1.27–3.32）** は単変量・多変量のどちらで、何例での値でしょうか。Figure 3 の単変量 HR 1.89 と合わせるために伺います。
